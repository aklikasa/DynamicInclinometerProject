\chapter*{项目总论与当前研发范围}
\addcontentsline{toc}{chapter}{项目总论与当前研发范围}
动态倾角仪面向持续变化和振动干扰条件下的倾斜角测量。整个项目未来包括器件基础测试、常温内参、温度补偿、随机噪声分析、嵌入式参数应用、姿态融合、整机性能验证和生产放行等研发阶段。各阶段必须共享明确的坐标系、量程、单位、设备计量与数据追溯体系。

\begin{notice}
\textbf{本版工作范围：}\textbf{第一阶段}详细记录常温 ACC/GYRO 参数辨识、A/B/C 模型比较及独立验证；\textbf{第二阶段}详细记录 2FDT600WK + PLC 温箱联合自动温补、数据采集、温度模型、验证与安全约束。\textbf{后续阶段}只写路线图，不预设研发结论。
\end{notice}
