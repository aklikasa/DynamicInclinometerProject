# WPF 研发测试平台：Windows 打包交付工具（与现有工程配套）

放置结构（请注意解压后不要多一层目录）：

DynamicInclinometerLab/
    DynamicInclinometer.slnx
    src/
    tests/
    samples/
    vendor/
    packaging/
        发布并打包.ps1
        DynamicInclinometerLab.iss
        安装须知.txt

环境：Windows 10/11 x64，.NET 10 SDK。第一次还原 NuGet 可能需要网络。
可选：安装 Inno Setup 6 或 7（安装 ISCC.exe），用于制作 Setup.exe。

在工程根目录打开 PowerShell，执行：

    powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\发布并打包.ps1

它会执行：还原 NuGet → SmokeTests → Release win-x64 自包含 publish → Portable.zip → 如找到 Inno Setup 则生成 Setup.exe → SHA256.txt。
输出：工程根目录的 dist\ 文件夹。可以优先将 Setup.exe 分发给同事，无 Inno Setup 时可以分发 Portable.zip（解压整个目录后运行 DynamicInclinometer.App.exe）。

也可以手工发布：

    dotnet publish src\DynamicInclinometer.App\DynamicInclinometer.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishTrimmed=false -o publish\win-x64

包装策略：采用多文件发布、单文件安装器。因为项目依赖原生 x64 的 2TD600.dll，不推荐贸然使用 .NET PublishSingleFile。
发布包不附带设备 0002 的校准文件，以防客户误用于其他物理设备；必须按实际设备编号单独交付 ACC/GYRO JSON。

注意：此脚本没有在 Windows 执行编译，最终安装包还必须在真实机器验收。2TD600 厂商 DLL 的其它依赖、COM 驱动以及仪器机械安全不由 dotnet publish 自动验证。
不要将当前研发软件标成正式出厂合格版本。
