# 这次的转台控制纠错版——先看这里

本包是 **WPF 完整源码工程**，没有包含可直接双击的 EXE，也没有经过 Windows 编译或转台真机验收。

## Windows 构建

1. 解压 ZIP 文件。
2. 在有 `.NET 10 SDK` 的 Windows 电脑打开 `DynamicInclinometer.slnx`；或者使用根目录 `构建和测试.ps1`。
3. 使用 `一键发布_Windows.ps1` 后，程序输出位于 `dist/win-x64`。

## 控制页（已按旧标定上位机修订）

- 左右两轴始终显示**绝对角位置**（编码器反馈）。
- 默认选择“相对位置（增量角）”，输入 +5 是在当前位置基础上增加 5 度；可以切换到“绝对位置（目标角）”，输入 5 是定位到显示角度 5 度。实际转动方向和零位需要现场核验。
- 速率输入范围 0.01～60°/s；首次测试强烈建议小角度、低速。超过 10°/s 会再次提示确认。
- 允许两个轴分别发送命令，也可点击“双轴联合运行”，该动作通过旧 Python 上位机同一 DLL 的联合控制接口实现，但需要确认负载安装状态下确实允许两轴共同运动。
- 恢复三个厂家回零按钮：内轴机械回零、外轴机械回零、双轴机械回零。双轴机械回零为依次执行，不是同时找零。
- “双轴使能 / 检查”以真实设备反馈为准，已经使能则不会重复使能；自动测试同样按真实反馈检查。
- 状态读数字段使用固定几何布局，不再随新角度反馈重新换行和改变卡片高度。

## 自动测试

真实 IMU 校准融合后可输出 Roll/Pitch、实时曲线与 3D 姿态。自动测试仍分为受控机械找零、低速预定位、转台摇摆、记录编码器与IMU数据、保存研发报告。驱动反馈必须真实有效；仿真不得混作实测，研究报告不表示精度检定合格。

## 安全

说明书第3.2节对部分装夹方向规定内/外轴不能随意同时转动；首次联动、回零和高速运动必须现场确认空隙、工装、线束和实体急停。当前机器上没有进行过真正的双轴联动回零测试。

详见 `README.md` 和 `docs/20261027_手动控制与联动重构说明.md`。
