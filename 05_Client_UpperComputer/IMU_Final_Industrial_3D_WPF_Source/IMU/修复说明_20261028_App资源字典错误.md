# 修复说明：App.xaml 资源字典不能包含文本（2026-10-28）

## 用户出现的错误

- 每个字典条目都必须有一个关联的关键字。
- 命名空间“LiquidGlassPane”中不存在名称“clr-namespace:DynamicInclinometer.App.Controls”。
- IDictionary 或 Array 属性下的文本无效。行 54/55。
- 不允许将文本作为字典或数组属性中的内容。

## 真正根因（已经在原始 ZIP 的源码中定位）

`src/DynamicInclinometer.App/App.xaml` 原来的 XML 为：

```xml
  </Style>
\n  <Style x:Key="SectionLabel" TargetType="TextBlock">
```

`\n` 是两个真实字符，不是空白/换行。它落在 `<Application.Resources>` 字典节点中。普通 XML 解析器允许文本节点，但 WPF 资源字典不允许这种文本节点，导致 XAML 编译失败，并产生控件 CLR 命名空间的连锁错误。

本版移除了该文本字符，保留 `glass:LiquidGlassPane` 的 `ContentControl` + `ControlTemplate` 结构，避免外部 x:Name 与 UserControl 名称作用域冲突。

## 增强检查

- 校验所有 XAML / csproj XML 格式。
- **另外**检查 WPF 资源字典：不能包含非空文本节点、每个资源必须有 `x:Key` 或有效隐式 Style。
- 检查 `glass` CLR 命名空间与 `Controls/LiquidGlassPane.cs` 中实际类一致。
- 检查 XAML 所有实际事件绑定能够在对应 C# 文件中找到处理器。
- 保留 GPU HLSL 编译流程、ABS/REL、IMU/ESKF、转台手动操作及删除自动测试页面的结构。

本环境未配置 Windows .NET/WPF 构建工具，因此完成的是增强静态校验，不等于真实 Windows 编译成功，也不等于通过真实转台安全验收。请在 Windows 电脑上打开 `.slnx` 重新生成；如有新错误请优先复制“输出 > 生成”的第一条错误。
