# 真实金属 IMU 3D 模型升级（基于完整 Precision Glass 工程）

## 这次真正更改了什么

原先 `MainWindow.BuildPcb()` 只绘制一块青色几何平板。现在它真正创建了一套 WPF `MeshGeometry3D` 三维模型，**不是图片覆盖**：

- 带多层倒角的铝合金 IMU 外壳、顶盖和橡胶接缝；金属漫反射与高光材质。
- 四颗立体十字螺钉、前侧接口触点、顶部状态灯。
- 贴在真实三维顶面的文字铭牌（WPF 离屏生成位图纹理并映射到模型表面）。
- 固定在世界坐标的 360° 圆形双刻度盘（每 5° 一刻度）、机身坐标箭头与固定参考轴。
- 支持鼠标左键拖动旋转**观察相机**、滚轮缩放、重置视角、隐藏坐标轴、自动绕机身旋转观察视角。
- 姿态仍由现有 ESKF/ABS/REL 姿态四元数 `_rotation.Quaternion` 驱动；切换相机绝不会改算法数据。

新增文件：`src/DynamicInclinometer.App/Controls/IndustrialImu3D.cs`。没有引入 HelixToolkit 或其他外部三维 NuGet 包，因此不会额外产生网络包恢复或本地 ShaderBuild 环节。

## 注意：和效果图的界限

1. **这是真实可交互三维几何与光照，不是静态图片。** 不过此版采用原生 WPF 3D 的传统材质与高光，**不是完整 PBR/环境反射渲染引擎**，不能保证像概念渲染图那样完全照片级真实。
2. 模型是**通用工业 IMU 外壳示意**，不是你真实传感器的 CAD。螺丝、外壳轮廓、铭牌、接口按工业外观设计的示意比例构建；如果要同实物一比一，需要厂家尺寸图、CAD（STEP/OBJ）或设备多角度照片。
3. 环形刻度盘只是视觉世界坐标参考，不能当作机械转台的位置编码器读数；指针姿态数据还是来自真实 IMU 解算。
4. 除三维视图逻辑、鼠标交互和文档外，**IMU 采集、标定、ESKF 算法和 2TD600 转台驱动不变**。自动测试页面继续隐藏，不主动运行硬件。

## Windows 运行

打开 `DynamicInclinometer.slnx`，在 Visual Studio 2022 支持 .NET 10 的版本中选择 `DynamicInclinometer.App` 为启动项目并重新生成。若仅验证编译，可运行 `Windows_只编译验证_不启动转台.ps1`。

**此环境没有 Windows WPF 编译器与真机，项目完成的是静态检查及代码实现，没有完成 Windows 运行截图和实机测量验收。** 不能把此静态检查视为产品成品验收。
