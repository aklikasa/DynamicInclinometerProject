# 2026-10-27 · 界面可读性与布局重设计

## 问题与解决方式

截图中的“报告保存目录”文本发生纵向裁切，旧版 TextBox 模板使用带 `Padding="13,9"` 的外层 Border 包裹 `PART_ContentHost`，固定输入框高度与 WPF 文本视图的排版区域容易互相挤压。

新版将**输入框外边框的内边距清零**，在 `PART_ContentHost` 内部通过 `Margin="13,0"` 与 `VerticalAlignment="Center"` 单独排版单行文字；多行日志输入框使用独立 `AcceptsReturn=True` 模板触发器，保持拉伸和上下间距，避免单行修复影响运行日志。输入框使用白底、深色字和高对比边框，并在获得键盘焦点时强调描边。

## 布局与视觉体系

- 将全局视觉改为**轻量专业仪器控制台**：灰白中性底、清晰纯白表面、克制的深青蓝主色、16 px 卡片圆角、10 px 控件圆角、小面积低强度投影，移除模糊的装饰性巨型光晕。
- 顶部仪器身份、连接状态、设备串口操作彼此分层；页签改用简洁的选中下划线。
- 自动测试页布局按 **01 测试参数 / 02 保存报告 / 03 执行测试** 排列，输入项规则对齐；报告路径与“浏览目录”按钮并列，直接展示路径前缀并允许横向编辑滚动。
- `ReportDirectoryBox.ToolTip` 绑定输入框当前 `Text`，悬停可以查看完整路径。
- 将报告内容归为简洁的内容标签；将工况安全限制和研发报告限制保留在可读的位置。
- 按钮采用主操作、普通操作、停止/危险操作三种视觉层级。保留原算法参数、实时测量和转台运动的 C# 逻辑不变。
