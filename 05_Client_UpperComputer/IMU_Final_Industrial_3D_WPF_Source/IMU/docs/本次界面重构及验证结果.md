# 2026-10-27 产品化界面统一改造

1. 以 `DynamicInclinometer_ProductUI_20261027.zip` 为基础整理，保留全部源码、驱动 DLL、校准示例与测试脚本。
2. 全局统一淡蓝渐变、半透明白玻璃卡片、双层阴影、胶囊按钮和输入框、深色下拉菜单文字。说明：WPF 使用渐变与阴影模拟玻璃视觉，未实现 Windows DWM 的真实逐像素背景模糊。
3. 实时监测页突出标定后的 ESKF Roll/Pitch 数字、3D XYZ 轴和实时趋势；设备编号默认空白，未连接时不得显示伪造测量值。
4. 自动测试页改为参数、报告路径、进度三个主要区域，历史 CSV 报告与研究设置可折叠。
5. 转台控制采用左右对称内外轴控制卡，删掉所有可见高级安全/摇摆预检 UI。两个轴各自速度输入；运行时验证状态，首次电机指令弹出现场安全确认，单步位移大于 5° 时追加运动目标确认。
6. 安全修复：删除过去 `SafetyConfirmed.IsChecked=true` / 自动 `_armed=true` 等隐藏放行代码。未经核实的 `SetAxisSway` ABI 原生调用被明确禁用。
7. 原有自动报告代码和 CSV 导入逻辑保留，但真实自动摇摆**未开放**；已有的报告标记为研究用途，非 QC PASS。
8. **验证界限**：已执行 XAML/XML 解析、控件事件/字段引用检查、源码历史错误检查和 ZIP CRC 检验。未执行 Windows WPF 编译、COM 设备通信及实际转台运动，不能承诺零编译错误或已实机验收。
