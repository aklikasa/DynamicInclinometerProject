# 2TD-600 自动测试接入说明 · 2026-10-27

## 确认依据

- 使用维护说明书：U-T 双轴速率位置转台，位置/速率/摇摆模式；外轴+内轴角速率均到 ±60°/s。支持远程串口控制。说明书未给角速度精度、角加速度精度保证，不能直接推断动态角度误差。
- 说明书附录 A：状态帧 0xA0 含轴状态、角位置、角速率；找零完成状态独立于当前位置。运动指令 A2+D3 为摇摆，参数1=幅值(deg)，参数2=频率(Hz)。
- 上次上传的旧标定上位机 `turntable/turntable_2TD600_comm.py` 使用 `ctypes.CDLL`，已指定 `SetAxisFindZero(int,double,double)->int`、`GetAxisFindZero(int)->int`、`SetAxisSway(int,double,double)->int`、`GetAxisLock(int)->int`，DLL 导出表含同名函数。此处的 ABI 核对不是电机实测。
- SST810 测试样式：幅值5°、频率0.3Hz，横摇/纵倾分别展示姿态及误差图。可借鉴试验工况与图表形式，但不能继承样例公司的判定状态。

## 自动测试状态机（已实现）

1. 现场操作员在转台页建立连接，等待有效反馈、确认机械安全，使能两轴。真实采集必须来自真实IMU，且已有对应ACC/GYRO标定并选择ESKF。
2. 点击“开始自动测试”→ 实机现场二次确认。预检无故障/限位/锁紧，轴速低于静止阈值；未经确认不动作。
3. 依序处理外轴2和内轴0：先读取 `GetAxisFindZero`，为0时低速下发 `SetAxisFindZero`；持续读回零位完成、正常状态和零速，并监督非运动轴的位置/速度。
4. 机械找零完成后，确认外轴0°和内轴0°或90°；若必要自动缓速定位。位置跨度大于90°时需操作员额外授权完整路径后才可执行≤20°分段低速定位；跨越角度周界且路径不明时仍拒绝自动运动。
5. 执行 `SetAxisSway(2, amplitude, frequency)`，验证运动真的发生、幅值包络、内轴不动和异常速度；一旦传感器断流、异常反馈或用户停止，进入停止状态。
6. 正常结束或异常时请求双轴软件停车，要求连续零速/位置稳定反馈；停车不能证实则弹出故障，实体急停必须由现场人员操作。
7. 仅使用真实硬件采样生成对标研究报告；保留原始记录、反馈、标定信息和未验收限定说明。

## 自动安全限制

- 真实摇摆：幅值>0且≤30°，频率0.02–0.5 Hz，峰值角速度 `2πfA` ≤20°/s。5°/0.3Hz 的峰速约9.42°/s。不能用角速度范围来推出波形精度或者加速度能力。
- 找零：每轴约1°/s、2°/s²、最多432s；未获得连续3次找零完成及零速时绝不当作成功。现场需事先核查转台全行程和运动方向。若真实最大允许加速度更低，应据厂商要求下调。
- 自动定位：1°/s，单段最大20°。跨度>90°需额外现场路径授权，每段连续3次到位/零速/厂家到位标志确认。0°与360°邻近位置视为同一静止零位；跨角度周界路径不明确时仍会拦截。
- 软件与系统的串口通讯不是急停回路：RS232链路断开、窗口崩溃、DLL卡死均可能使软件无法成功制动。**实体急停与场地隔离是运行前提**。
- 参考厂商报告的“QC PASS”与本项目无关。动态角误差需 IMU / 编码器硬件级时间基、安装轴符号和参考量值审核后才可出正式结论。

## IMU 数据时间策略

- 若 MCU tick 字段突然出现远大于主机实际经过时间的跳变，原程序不断将成功CRC计为通信恢复，然后反复“错误1/3”。此版会保留CRC/帧完整性校验，异常时记录 `prev/curr/delta/hostGap`，研究级连接切换到主机单调时钟批次重建，不再频繁抛出相同异常；`TimingVerified` 仍为 `false`。
- 16 样本 FIFO 的时间重建依赖候选 ODR，必须由固件验证寄存器含义才可升级为可信时标。若 IMU 没有可靠时间参数，滤波后的 Roll/Pitch 是**可观察的工程输出，不是精度保证**。

## 尚须实物验证（交付前必须现场完成）

- .NET 10 WPF build / smoke 测试；Python工具对DLL的签名验证 ≠ WPF P/Invoke 在生产环境验证。
- GetAxisFindZero、GetAxisLock、GetRunMode状态含义，首次找零方向/行程，以及软停车与实体急停。
- 摇摆 `SetAxisSway` 幅值和频率的实际响应、相位、中心角及边界，尤其是内轴90°时工装的机械干涉。
- ACC/GYRO 标定坐标方向、Roll/Pitch 正负和IMU在转台上的轴向；高频运动下因非重力加速度而产生的ESKF观测拒绝。
- IMU FIFO 内容是否完整、不重复，真实采样时标 / ODR 和两条采集链路的延迟；后续再讨论 ±0.02°动态精度。
