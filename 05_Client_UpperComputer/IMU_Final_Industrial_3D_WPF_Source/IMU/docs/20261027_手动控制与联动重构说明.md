# 转台控制纠错版（未进行 Windows 实机验收）

## 对照旧标定上位机

- 旧 `turntable_2TD600_comm.py`：`SetAxisPosition`（绝对）、`SetAxisOpposition`（相对）、`SetUniteAxisAction`（多轴联合）、`SetAxisFindZero`（机械找零）、`GetAxisEnable`（真实使能反馈）。本次 WPF 使用相同 API 和轴号（内0/外2）。
- 恢复每轴相对/绝对模式，默认相对增量；无论何种运动指令，状态栏永远显示厂家反馈的绝对角度。
- 恢复内轴/外轴/双轴机械回零按钮。双轴机械找零按内轴->外轴顺序，不同时发送找零。
- 新增双轴联合运行按钮，DLL 先预装内轴（init=true,run=false），再装外轴并统一触发（init=false,run=true）；这两个标志的实际运动一致性待转台验证。
- 额定位置运动速度输入放宽为0.01～60°/s，与说明书内外轴额定速率一致；10°/s以上和大位移需二次确认，额定最大值不是推荐运行速度或动态精度指标。
- 自动测试准备不再要求用户在手动页再使能一次；先读取真实反馈，已使能即复用，未使能才明确征询操作员。
- 固定文字读数区大小，单行不换行，避免180ms状态更新导致左右卡片高度抖动；一次刷新不再重复读取两遍两轴。

## 重要安全边界

说明书负载章节要求部分装配姿态下一轴静止（如内框连续旋转要求外框零位静止），所以“双轴联合运动”是用户许可的实验功能，不是无条件安全模式。操作者必须现场验证工装间隙、线束路径、使能及实体急停。位移不按最短路径推断。

回零分为“完成机械找零”与“当前绝对位置0°”。自动测试会分别核实两者，机械找零可能产生较大运动。联动及高转速未经过现场运动验证，首次调试优先使用小角度、低速。

## 状态

- 静态 XML 及事件绑定检查可在任何系统执行。
- 本沙盒没有 Windows / .NET SDK / 真实转台，无法保证 WPF 编译通过或厂家 DLL 的联合启动语义；必须在Windows构建并按小角度低速顺序做现场验收。
