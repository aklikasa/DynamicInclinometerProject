# Dynamic Inclinometer — Precision Glass 客户界面版

这是基于用户上传的 **IMU_LiquidGlass_XAML_Resources_Fixed_Full_Source** 完整 WPF 工程修改的源码，目标是呈现“石墨黑 × 银灰原生液态玻璃”的高端工业仪器界面，**不是在截图上盖 UI**。

## Windows 启动

1. 备份之前能够运行的旧项目，不要覆盖。
2. 需要 Windows、Visual Studio 的 .NET 桌面工作负载和 .NET 10 SDK，打开 `DynamicInclinometer.slnx`。
3. 运行 `Windows_只编译验证_不启动转台.ps1` 进行安全的**编译检查**，或在 VS 中选择 `DynamicInclinometer.App` 为启动项目、重新生成 Debug。
4. 确认 Debug EXE 已生成（GPU HLSL 在运行时编译/回退，不要求磁盘存在 `.ps`），再启动查看空设备界面，导入正确的 ACC/GYRO 标定并连接真实 IMU。
5. 只有操作人员核对负载、线缆、机械限位和实体急停后，才能尝试转台手动运动。

## 实际已整合的页面

- 侧边导航：「实时测量」和「转台控制」为真实页面；「数据记录」打开已有记录目录；「参数与诊断」展开真正的高级设置。
- 两枚 Roll/Pitch 仪表指针跟随真实姿态数值，没有新模拟采集器。
- 中心保留原 WPF `Viewport3D` 实时设备坐标显示。
- 实时曲线继续由原 IMU 样本列表驱动。
- ABS/REL 模式、REL 手动参考零点、标定导入、ESKF、真实 CSV 记录均保留。
- GPU 背景折射沿用已建立的 `LiquidGlassPane : ContentControl` 与 HLSL shader，性能开关和强度滑杆移到高级参数折叠区，不再占据首页卡片。
- 自动测试 UI 不再显示或触发；旧自动分析代码未作破坏性删除。
- 实时数据过期或停止后，仪表数字回到 `--.---°`，不再展示历史值冒充实时数据。

## 重要限制

**这个包是源码级 UI 实现，不是经过客户验收的商业发行版本。** 本环境无 Windows WPF 编译器，无法在此完成真实编译、画面截图或 2TD-600 联机验证。请参见 `README_产品视觉重设计.md` 和 `tools/qa_product_ui.py`。原标定、设备通信和转台安全逻辑未被本轮视觉改版重写。

使用本程序进行计量评估前，仍必须完成固件采样时标、量程、方向矩阵、延迟及测量精度的实测验证，不能把客户展示效果视为计量认证。

## 最新连接 / 记录操作变更（重要）

详见 `README_连接监测和手动记录_ODR说明.md`。现在连接仅启动实时监测，不生成任何 CSV；“开始采集 / 停止采集”仅负责数据落盘，停止后继续实时监测；断开设备才终止数据流。当前首页处理率是最近约1秒的实测处理值，**不是** ASM330LHHX 寄存器已证实的内部 ODR。
