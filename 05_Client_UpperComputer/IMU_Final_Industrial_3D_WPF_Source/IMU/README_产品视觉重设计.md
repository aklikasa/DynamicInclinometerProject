# Precision Glass / 2026 客户界面重设计

## 定位和限制

以客户演示视觉稿为**信息布局和气质参考**，不是图片贴图：本文件是可编辑的 WPF XAML 与 HLSL 源码，所有读数仍与原有 `MainWindow.xaml.cs` 的实际 IMU 数据绑定，绝不填入示意图的角度值。背景是低饱和石墨、烟灰玻璃、银灰边框和少量青绿色。保留用户确认喜欢的原生 HLSL shader 背景折射，并设置 GPU 开关与强度调节。

## 新界面

- 固定左侧导航：实时测量、转台控制、打开数据记录、参数与诊断（后两项不是虚构页面）。
- 统一顶栏：品牌、真实状态、GPU 特效开关；连接和停止采集在独立操作条。
- 首页 Hero：真实的 Roll/Pitch 数字与仪表指针、Yaw 参考说明、原有 3D 姿态。
- 第二行：实时 Roll/Pitch 曲线及真实 IMU 状态摘要。
- 第三行：ABS/REL 参考、ACC/GYRO 标定导入、数据记录目录。
- 高级设置默认收起：时标策略、诊断配置、工程级融合和滤波器重置。
- 转台页保留原轴号、真实编码器状态、手动定位、机械找零和联合控制代码，使用一致的中性玻璃外观。
- 原自动测试页面没有恢复；旧测试辅助源代码保留以避免对记录器/设备层做破坏性重构，没有自动测试菜单或启动按钮。

## 数据完整性及安全

- 未连接时 Roll/Pitch 保持 `--.---°`，没有演示读数；指针在断连/流过期时降为低对比度。
- ABS 是重力参考倾角，REL 须由操作者手动设置参考姿态；原始保存的 ABS 数据不受显示模式影响。
- Yaw 没有磁/外部参考，不标成绝对真北航向。
- 真实采集时间基未验证时仍有研究级安全警示；不能把此界面作为校准合格证明。
- 转台机械行程、急停、限位和多轴运动必须由现场人员验收，视觉重设计不等于运动安全测试通过。

## 编译及验收

Windows + .NET 10 SDK / VS .NET 桌面开发，打开 `DynamicInclinometer.slnx` 或运行 `Windows_只编译验证_不启动转台.ps1`。
当前容器**没有 Windows WPF 编译器，未执行真实 Windows 构建或实机测试**。本 ZIP 已完成 XAML/绑定/项目资源/打包静态检查。用户确认视觉稿后，在本机检查 1600×900 和 1366×768 分辨率、系统 DPI、GPU shader 编译、键盘焦点、真实连接状态、显示抖动和长时间资源占用。
