# Dynamic Inclinometer — 客户三维区域第二版（紧凑布局 / 金属 IMU）

## 本次完成的代码改动
这是一份 **完整 C# WPF 工程**，不是界面示意图、PNG 或分散的补丁。

### 1. 真实可交互的三维模型
`src/DynamicInclinometer.App/Controls/IndustrialImu3D.cs`
- 参考提供的实物照片，采用无品牌工业动态倾角仪外观：铝合金壳体、层叠上盖、长边纵向侧筋、四个安装耳及通孔、短边圆形金属接口、无商标深色铭牌。
- 圆形接口与固定孔为三维几何网格，不是贴图/静态图片。端子排列只用于视觉展示，不代表真实接插件引脚。
- 默认较低饱和度的银灰材质、明暗轮廓高光、参考刻度盘、XYZ 坐标轴。使用 WPF 自带的 MeshGeometry3D / 材质，不新增 NuGet 依赖。
- **注意**：这是外观近似模型，**不是厂商 CAD 或可用于加工的准确尺寸**；没有使用照片中的品牌、商标、产品型号。

### 2. 留白优先的三维区布局
`src/DynamicInclinometer.App/MainWindow.xaml`
- 三维视窗以独立浅边框呈现，获得更连续的展示空间。
- “复位视角／隐藏坐标轴／环绕视角／设置 REL 零点”整理为一排紧凑按钮。
- 状态文字改为顶部和底部短行，不挤占模型中央。
- Roll/Pitch/Yaw 左栏宽度微调，让右侧三维可视区域更宽。
- 如需要更大的 3D 视图，可把主窗拉宽；用户也可通过滚轮调整模型距离。

### 3. 更合适的默认镜头
`src/DynamicInclinometer.App/MainWindow.xaml.cs`
- 复位时改为 3/4 斜侧视角：方位 -135°、俯仰 28°、距离 9.7（原距离 7.85）。
- 默认可看见上盖、长边侧筋与左端圆形接口，留出更多四周空间。
- 鼠标拖拽只操作观察相机，**绝不更改 ESKF 四元数**；实时姿态仍由原有 `_rotation` 驱动。

## 保留的功能
- IMU 连接即在线监测，单独开始/停止数据落盘。
- ABS/REL、ACC/GYRO 标定导入、ESKF、曲线、记录、ODR 提示、转台手动控制等源文件保持不变。
- 自动测试页面仍不提供。
- 相关转台动作仍必须遵守实际设备安全确认程序。

## 编译方式
- 为避免 Windows 默认路径长度引起的 MSBuild 错误，**建议把 ZIP 内的 `IMU` 文件夹直接解压到 `D:\`，得到 `D:\IMU\DynamicInclinometer.slnx`**。
- 在 Visual Studio 中打开解决方案，清理并重新生成 Debug；先仅启动界面检查，再连接 IMU。无需运行转台。
- 可以运行 `tools/qa_realistic_3d.py` 进行静态结构检查（此项不能代替 Windows 编译）。
