# 2TD600 转台控制补充说明（第三版）

## 本次依据

依据工程中随附的《杭州浙达 2TD-600 双轴转台使用维护说明书（文件代号 JC10468YS，2023-03）》以及工程里的 `2TD600.dll` Python 封装。

## 已核对的转台控制功能

| 功能 | 手册 / DLL 支持情况 | 当前上位机情况 |
|---|---|---|
| 绝对位置运动 | DLL 导出 `SetAxisPosition` | 本版在内轴、外轴位置控制区增加模式选择 |
| 相对位置运动 | DLL 导出 `SetAxisOpposition` | 保留，默认模式仍为相对位置，兼容旧操作 |
| 连续速率运动 | DLL 导出 `SetAxisVelocity` | 保留；本版增加可编辑角加速度，原代码将加速度硬编码为 10 |
| 摇摆运动 | DLL 导出 `SetAxisSway` | 原界面已具备幅值、频率、运行和停车控件，不需要重复造一套 |
| 单轴回零 / 全部回零 | DLL 导出 `SetAxisFindZero` 和原界面回零按钮 | 原界面已有 |
| 停车、使能、断使能 | DLL 导出对应函数 | 原界面已有停车和连接时的使能流程 |
| 位置、速率、运动模式、到位状态 | DLL 导出读取接口 | 原界面已有状态显示 |
| 限位、超速、超差、驱动故障、电压异常 | DLL 导出读取接口 | 原界面已有状态显示与故障监测 |

## 本版修改

1. 在内轴、外轴位置控制区分别增加“相对位置（增量）/绝对位置（目标角）”选择。
2. 位置运行按钮依据选择调用 `SetAxisOpposition` 或 `SetAxisPosition`（2FDT600WK 分支调用对应厂商接口）。
3. 连续速率模式增加“加速度”输入框，不再固定使用 10°/s²。
4. 修正 2TD600 运动模式状态码映射：状态码 4 为速率，状态码 5 为摇摆；原代码将状态码 4 错标为摇摆且没有正确显示速率模式。

## 需要注意的接口限制

当前工程中的 `2TD600.dll` Python 封装，绝对位置 / 相对位置函数只暴露“目标角度、目标速率”参数，没有暴露单次位置命令的角加速度参数。因此，本版没有在位置运动区虚构一个不起作用的加速度输入框。若要从软件设置位置运动的角加速度，需要厂商确认是否存在其他 DLL API 或控制器参数配置接口。

摇摆运动在 DLL 中有 `SetAxisSway(axis, amplitude, frequency)` 接口，单位分别为度和 Hz。摇摆幅值与频率控件原本已经存在，仍在“运动控制”页签中。

手册说明连续无限旋转存在安装姿态约束：负载安装后，某些条件下内轴需保持静止，另一些条件下外轴需保持零度静止。不能把“支持 360° 连续旋转”理解为任意姿态下两个轴都可同时无限旋转。

## 本次补充：转台开关按钮

- 转台页面保留一个切换按钮：软件启动时显示“打开转台”；通信打开后显示“关闭转台”。
- 点击“打开转台”会打开所选型号的通信端口并使能两轴；完成启动流程后开放运动控制。
- 转台通信打开期间禁用型号选择，避免关闭时误按另一型号的接口。
- 点击“关闭转台”时先向两轴发送停车命令，并等待新的状态反馈确认停车；若未能确认停车，则保留通信并提示检查，不强行关闭。
- 状态反馈线程在可能触发回零运动的命令之前启动，以便启动过程异常时仍可通过同一按钮执行受控停车。
- IMU 标定页已同步更新转台连接状态判断，识别“关闭转台”按钮状态，不影响原有连接/断开流程。
- 以上仅完成软件逻辑与静态检查，尚未连接真实转台进行硬件联调。首次测试请低速、单轴、短时进行，并确认硬件急停可用。
