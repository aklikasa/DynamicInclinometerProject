WINDOWS-COMPATIBLE SOURCE ARCHIVE

This is a repack of the previously delivered Python project.
Only NON-ASCII filenames have been renamed for compatibility.
Source code, DLLs, configs, and file contents are unchanged.

1. Extract the ZIP into a short local path, for example C:\IMU\.
2. Open TiltSensorCalibration.
3. Double-click START_WORKSTATION.bat or run: python main.py
4. Run RUN_OFFLINE_TESTS.bat to check source/tests before hardware work.
5. Do not run unattended temperature or turntable movement until the
   actual PLC/RS422/IMU signals and safety interlocks are validated.

Previous archive was CRC-valid in Python/unzip, but Windows Explorer
reported an unsupported/invalid ZIP on the user's machine.
This archive uses plain ZIP_STORED entries and ASCII-only paths.
