# 动态倾角仪工作台 · 精简玻璃质感版

本包是在原始「TiltSensorCalibration_IMU串口识别修复版」源码基础上修改的**完整源码项目**，不是 Windows 可执行安装包。保留 2TD600/2FDT600WK 通讯、温箱、六轴 IMU 自动标定及相关数据模块；**本次不修改 IMU 标定算法**。

## 主要修改

- 主窗口恢复原版 **1144 × 723**，不再强制显示宽大的 1460 × 900 窗口。
- 统一为暖白、石墨灰的轻玻璃界面：圆角、浅层渐变、细致高光；没有蓝色主按钮。Qt QSS 不能实现 Apple 原生的背景折射/动态模糊，因此这里是**静态玻璃质感**。
- 左侧依次为 **01 设备连接 → 02 通讯与采样状态 → 03 实时数据 / 数据记录**，右侧优先显示 **IMU 标定**，另保留转台、温箱页面。
- 删除柔性测斜仪遗留的阵列数、节数、XX 通讯地址、AIA 设置整组，以及数据区中遗留的校准计算、温漂补偿、FTP 和故障统计页面。旧「倾角仪校准」页面在启动后从主导航隐藏，原有对象保留以确保兼容旧模块；以后需要可从 `main.py` 恢复。
- 左侧数据记录仅有 **一个按钮**：开始记录时创建新的 CSV，变成「停止记录」；停止时关闭并完成缓冲写盘，回到「开始记录」。目录选择改用 Qt 文件夹对话框；录制期间不允许切换目录。打开 IMU 串口、文件夹路径有效是开始记录的前置条件。
- IMU 标定页面的「实验编号与原始数据记录」也改成 **一个按钮切换开始/停止**。该记录会生成包含 `imu_raw.csv`、`turntable_feedback.csv`、`events.csv` 等的实验文件包，与左侧普通 CSV 记录互斥，避免双重记录混淆。
- 转台、温箱原来运行时显示的纯红 / 纯绿色块改为低饱和状态显示，**保留绿色正常、红色异常的语义**。
- 修复旧界面在部分校准项目关闭时，页面显示判断引用未定义变量的问题。

## Windows 使用

1. 保留 DLL、`config.xml` 与全部项目子目录；确保系统已安装相应 Python 环境和原项目依赖（`PySide6`、`pyserial`、`numpy`、`openpyxl`、`pandas`、兼容旧 API 的 `python-snap7` 等）。
2. 在项目根目录运行 `python main.py`，或者双击 `启动工作台.bat`。
3. 连接设备后，在左侧 **数据记录** 选择文件夹；点击 **开始记录** → 按钮变为 **停止记录** → 点击停止并完成写盘。
4. 若要记录转台反馈、标定日志及完整 IMU 原始数据包，切换右侧 **IMU 标定** 页面并使用该页的实验记录按钮。

**请勿在转台运动、温箱运行或数据写盘时直接强制终止 Python 进程；按原项目操作规程安全停机。**

## 修改文件

- `ui/mainWindow.ui` — 小尺寸玻璃界面，精简遗留控件与区域
- `form/form_tilt_sensor_cal.py` — 普通 CSV 单按钮记录、目录逻辑、状态显示
- `form/form_imu_calibration.py` — IMU 实验记录单按钮与玻璃样式（数学拟合代码未改）
- `form/form_turntable_ctrl.py`、`form/form_tc.py` — 状态显示配色
- `main.py` — 工作区导航顺序、路径与窗口初始化
- `tools/check_project.py` — 无设备静态与状态切换回归检查
