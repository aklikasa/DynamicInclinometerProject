# IMU 标定工作台第二版说明

## 本版改动

1. IMU 标定页不再显示转台端口选择、连接/断开、轴选择、目标速率、加速度和手动启动/停止运动控件。
2. 转台人工控制仍由原“转台”页面负责；IMU 页只读取共享转台连接状态和内外轴反馈。
3. 新增三个标定任务入口：加速度计位置计划、陀螺仪工况计划、六轴对齐输入检查。
4. 加速度计位置数默认 36，可设置稳定等待、采样时间和计划运动速率。
5. 计划文件写入用户选择的保存根目录；生成计划不会驱动转台，也不会覆盖原始数据。
6. 原始 IMU/转台反馈采集与事件记录机制保留。

## 重要限制

本版是界面职责分离与实验计划阶段，不是已经通过实机验证的全自动标定版本。按钮生成的是计划文件，不会自动控制转台，也不会伪造标定结果。

启用自动运动前，必须先在现场核实：

- 2TD600 内外轴的真实机械方向、旋转顺序、正方向和位置反馈含义；
- 角位置命令是否为绝对位置、360° 回绕语义以及每轴安全行程；
- 运动状态/到位状态的读取含义，停车后如何确认轴已停止；
- IMU 安装坐标与转台坐标之间的关系；
- 36 个机械位置能否提供足够的重力方向三维覆盖；
- 转台实际角速度反馈的准确度与不确定度。

## 当前工况计划

### 加速度计

默认 36 个位置，采用项目既有的内外轴等间隔网格生成计划。该网格仅是候选计划，不自动保证 36 个有效独立重力方向。计划生成后应先审查角度、限位和坐标定义。

输出文件：`accel_36_position_plan.json`（实际文件名由位置数决定）。

### 陀螺仪

生成静止、不同姿态、内/外轴正反向和多个目标速率的工况草案。参考角速度三维向量必须根据核实后的转台运动学模型计算；不能直接把某一轴的目标速率当作 IMU 坐标系中的参考向量。

输出文件：`gyro_rate_sweep_plan.json`。

### 六轴对齐

目前只检查是否存在 `accel_calibration.json` 和 `gyro_calibration.json` 两个输入文件，不执行坐标变换。必须先明确两份矩阵各自映射到哪个坐标系，避免重复旋转或把不可观测的安装角当作已知量。

## 验证情况

已执行 Python 语法编译检查。当前环境没有可用于验证的 Windows 实机、PySide6 运行环境与 2TD600 DLL 实时通讯，因此本版未完成实际 GUI、串口和运动联调。第一次实机测试应保持手动控制，不要根据计划文件直接执行自动运动。
