# 2026-11-05 WK 温补自动姿态定位修复说明

## 1. 本次实机证据

用户已在“转台”页面单独对外轴执行绝对位置定位：从约 359～360° 设置到 180°，外轴实际转动并到达 180°。

这证明该次手动单轴绝对定位可以正常执行。故障应继续聚焦在温补自动定位调用路径，而不是直接归因于转台机械机构或外轴无法执行 180° 绝对定位。

## 2. 代码对比发现

对比上传工程中的三个路径：

- 温补：`form/form_thermal_compensation.py` 的 `_move()`
- 手动位置控制：`form/form_turntable_ctrl.py` 的 `_wk_manual_position()` / `pushButton_AllRun_Click()`
- 既有 ACC 自动定位：`tilt_sensor_calibration/acc_cal.py`

发现温补原 `_move()` 有两项值得修复的差异：

1. 不论轴是否需要运动，都会给内轴和外轴都发送位置指令。用户这次的工况内轴本来就在 0°，仍会收到一次零转角指令。
2. 两轴位置指令连续发送，没有间隔；既有 ACC 自动定位流程在内轴指令后明确等待 100 ms，再发送外轴指令。

这两项差异与“手动单轴外轴 359°→180°成功，但自动温补组合定位失败”的现象相符。它们是目前最有证据支持的自动流程问题点，但最终仍需用修复版进行实机复验确认。

## 3. 本次修改

只修改 `form/form_thermal_compensation.py` 中温补专用姿态定位路径：

- 对距离目标不超过 0.2° 的轴跳过位置命令；该阈值与温补原有 ±0.2° 到位判据一致。
- 只对确实需要运动的轴发送位置指令。
- 多轴需要运动时，按轴分别加锁发送，并在两轴指令之间等待 100 ms，沿用现有 ACC 自动定位的发送节奏。
- 发送每个轴指令前重新核对该轴仍处于 1#伺服待命、无报警状态。
- DLL 返回成功后增加启动确认：控制器进入 3#位置运动状态、反馈角度变化、速度反馈或已到目标，任一条件可确认启动。
- 如果 DLL 返回 0，但 2 秒后控制器仍处于 1#伺服待命且角度没有变化，立即给出具体错误，不再空等原来的 240 秒。
- 保留原有 ±0.2° 到位判据、到位稳定 1 秒、240 秒整体定位超时及异常停车流程。

## 4. 保留范围

- 保留上一版 PV 初步到温 KeyError 修复（`pv_initial_range_c`、`pv_initial_slope_c_per_min`、`pv_final_tolerance_c`）。
- 保留 WK 8#→1#停车确认逻辑。
- 不修改温箱控制、温度稳定/热平衡判据、ACC/Gyro 标定算法、Gyro 三次多项式拟合、±250 dps量程配置、Gyro 多速率列表、手动位置控制和常温标定路径。
- 不通过放宽到位误差或单纯延长 240 秒超时来绕过故障。

## 5. 离线验证

新增 `tools/test_wk_thermal_position_dispatch.py`，使用假 DLL，不连接真实硬件，覆盖：

- 内轴已在目标位置时跳过零转角指令；
- 外轴 359.995°→180°按逆时针方向发送；
- 双轴都需要运动时，指令之间等待 100 ms；
- 识别 3#位置运动状态；
- DLL 返回 0 但控制器仍为 1#待命、角度不变时在 2 秒后提前报错；
- DLL 非零返回码被明确报告；
- 两轴均已在目标范围内时不发送位置指令。

本次新增加的 7 项测试全部通过；并且以下既有专项测试通过：

- 温箱稳定性：9 项；
- 分阶段温补状态机：5 项；
- WK 8#→1#停车：10 项；
- 温补断点续做：13 项；
- Gyro 多速率/方向：8 项；
- 温补状态机集成检查、页面结构检查、PLC自动状态机检查。

这些均为离线测试，不等同于实机联合验收。

## 6. 实机复验步骤

1. 退出上位机，备份当前工程和实验数据。
2. 使用本补丁覆盖工程根目录中的 `form/form_thermal_compensation.py`，并放入新增测试文件及更新后的回归测试 BAT。
3. 运行 `RUN_THERMAL_WK_REGRESSION_TESTS.bat`，确认专项测试通过。
4. 首次实机复验只做单温度点、受控运行；确认内轴已在目标角时日志明确显示跳过位置命令，外轴位置命令后出现“定位启动已确认”。
5. 确认实际角度到位、两轴速度归零、到位状态稳定后，再继续采集。现场人员应留在急停和温箱控制位置。

若复验仍失败，请保存完整日志，重点记录 DLL 返回码、外轴 GetAxisStateInfo 状态码、报警码和实际角度。不得在无人看护下运行。
