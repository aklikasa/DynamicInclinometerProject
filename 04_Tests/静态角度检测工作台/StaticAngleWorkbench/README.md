# 静态角度检测工作台 V1.3 · 双串口 / 外轴2使能 / 自动检测 / Excel可靠报告

独立 Windows 64 位 PySide6 项目。主界面 1060 × 690，日志面板默认隐藏。UI、采集通讯、转台适配、自动扫描、双级异常值剔除、Excel 导出分别封装，源文件全部为 UTF-8。

## 快速启动

1. 安装 **Windows 64 位 Python 3.10+**，解压整个项目，双击根目录 `启动工作台.bat`。首次启动需联网安装 `PySide6`、`pyserial`、`openpyxl`；Excel 导出只调用 `openpyxl`，不需要 `artifact_tool`。
2. 插入 IMU 和 2TD600 转台，点击底部 **刷新串口**，从 IMU 和转台两个下拉框各选择一个**真实检测到的、不同的 COM 口**（不再用 COM4/COM5 假默认值）。下拉框会显示设备描述；转台固定 115200，IMU 默认 1500000。确认实时加速度、内外轴位置、速度和故障状态正常。
3. 导入 `accel_calibration.json`，包含 `raw_accel_bias_g`、`raw_to_platform_matrix`。注意：示例标定为试运行资料，非正式出厂批准。
4. **先手动验证机械零位、角度正方向、两轴到位、限位保护、跨 0/360° 路径、线束活动范围。现场具备实体硬件急停。** 连接转台后点击 **使能双轴**（或各轴“使能”）。程序沿用旧工程轴号内轴0、外轴2，先发送使能命令，再等待驱动器并读回 `GetAxisEnable / GetAxisNormal`，不产生位置运动。如果使能后状态异常则不允许运动。软件的绝对定位 0° 并非硬件机械寻原点。
5. 在开始前选择 **Excel 输出路径**。设置静止时间（默认 3 s）和采样窗口（默认 5 s）；确认安全检查后，点击开始自动检测。若存在危险，请勿启动自动测试。
6. 自动流程：内轴 0、外轴 0 位置检查；内轴 0 下外轴从 −180 到 +180 每 10° 采点（Y 倾角），之后外轴返回 0，内轴 90，外轴重复扫描（X 倾角）；共 74 点。每点检查转台位置与速度反馈→静止等待→5 秒采样→两级 3×1.4826×MAD 处理→用 `M @ (raw-bias)` 计算倾角与转台 **实际位置反馈** 的圆周误差。
7. 结束自动在预选路径生成 Excel；中止/采样质量失败时发送双轴停车命令，并写出已有采点的部分报告（至少有 1 点时）。每完成一采点，会在报告同目录保存 `报告文件名.checkpoint.json`（与 Excel 同名主体）备份。报告包括：检测汇总、逐点结果、校准与参数及误差曲线。

## 自动运行的安全边界

- 厂商旧工程 DLL 只验证有 `SetAxisPosition` 等接口；**未确认真正机械寻零指令**。本软件仅检查和命令至编码器角度 0°，不承诺自动寻找机械参考零位。
- 旧接口采用 0~360° 绝对角度，负角变换为 `[0,360)`。**短路径/长路径、线束缠绕、轴向及参考角正负符号，需要操作员实机核实**。如果不能确认，禁止勾选安全确认启动。
- 上电使能需单独操作；不会自动使能。扫描发现故障、限位、未使能、定位超时、反馈超时或 IMU 断流会停止并触发双轴停车请求。**软件停车不是硬件急停，也不保证硬件按预期执行。**
- 单点最少 50 有效帧、最大剔除率 10%，超限终止，不伪造通过记录。角度公式：Y = `atan2(Py,Pz)`（内轴0）；X = `atan2(Px,Pz)`（内轴90）。这是基于原项目 `outer_x_inner_z` 模型的假设，正式出厂检测前要用已知角量具确认正方向与零位。
- 仅单向 74 点扫描，不构成往返滞后与全温度认证。±180° 重合姿态用于一致性比对，误差使用 `[-180,180)` 圆周角差。

## V1.1 实机排障步骤（针对“未使能”和量程日志刷屏）

1. 解压为全新目录，不要把新版覆盖在正在运行的旧项目 `.venv` 或源码目录上，退出旧上位机、确保端口未被其他程序占用。
2. 用 `start_windows.bat` 启动；点击 **刷新串口**，从 IMU 与 2TD600 两个下拉菜单分别选择系统实际检测到的端口。若设备未列出，先查 Windows 设备管理器与 USB 驱动，不要凭猜测填写 COM 号。
3. 点击“连接转台”，观察初始反馈：此时 `enabled=0` 可以是正常的未上电状态，`normal=0` 在未上电时不再堵住使能按钮。连接只是 `OpenPort` 成功，**不保证所有轴都已通信正常**。
4. 确认实体急停可用、机械区域无人、两轴无故障/限位后点击 **使能双轴**，确认提示。程序按“内轴0→等待→核验→外轴2→等待→核验”执行，**不会自动旋转**。如果某轴使能后 `GetAxisEnable` 未变 1，弹窗会显示具体状态；点击“诊断状态”会自动展开日志，保存日志供进一步分析。
5. 若显示“已使能/未就绪”，说明 DLL 回报 `enabled=1` 但 `normal=0` 或告警；禁止启动运动，先查驱动器供电、急停、报警和硬件联锁。
6. IMU `量程字段缺失` 不再每帧刷屏；它**不是通讯中断**，但说明加速度/角速度正按旧工程默认比例换算，**未核实真实量程前不能用于正式精度放行**。
7. 双轴均反馈 `enabled=1, normal=1` 并无故障/限位后，才可在人守现场条件下低速进行手动定位测试，然后考虑自动 74 点检测。

**离线验证说明：** 20项 Python 单元测试通过（包含模拟 DLL 对 `normal=0` 的未使能初态、故障拒绝上电、使能后状态未确认），Windows 真实转台与 Qt 界面未在当前环境测试。任何软件停车均不能替代硬件急停。


## V1.2：外轴使能 0/1 反馈及 0~360°

- 厂商 `2TD600.dll` 单串口管理两轴，内轴轴号 **0**，外轴轴号 **2**。旧工程发送 `SetAxisEnable(0)`、`SetAxisEnable(2)` 分别上电，之后延时读取状态。
- 自动检测前逐轴显示具体阻断原因：如 `外轴 2 enabled=0, normal=1` 就是**外轴未使能**，绝不是通信已断开或 normal=1 表示已使能。
- 增加显眼的「使能外轴 2」按钮。它必须由操作员确认才发送 `SetAxisEnable(2)`；DLL 返回1只表示命令已接收，连续轮询回读两轴反馈确认，失败记录更详细的诊断原因，不会跳过安全保护去自动运动。
- 两轴手动绝对目标角度输入范围均为 **0~360°**。UI 反馈显示归一到 0~360°，但不改变用于测量、误差计算与运动安全判断的 DLL 原始反馈值；负扫描计划角转换为合法的 0~360° 目标（如-10°→350°）。**0/360°角度数值等价并不证明旋转路径安全**，仍须现场确认。
- 增加 DLL 状态返回值严格校验：`GetAxisEnable/GetAxisNormal` 等状态 API 只接受0和1；其他返回值视为读取错误，防止将 -1 误判为已使能。
- **已知限制：** 当前没有真正的实机联调权限；若使能命令发送后外轴依然 feedback `enabled=0`，需要比较原上位机同一轴的反馈，检查现场驱动供电与硬件互锁。


## V1.3：修复 Excel 导出故障（重要）

- 旧版 V1.2 导出依赖 `artifact_tool`，Windows 普通 Python 未安装时会在**测完以后**报 `No module named 'artifact_tool'`。本版修正 `app/core/report.py`，仅依赖可通过 pip 安装的 `openpyxl`。`requirements.txt` 及启动脚本已更新。
- 每完成一个采点立即写入 `*.checkpoint.json`（UTF-8，原子替换），记录测量结果、校准零偏/矩阵、运行参数；即使最终 Excel 导出失败，也可在下次打开程序点击 **恢复备份**，不连接设备就重新生成 Excel。备份与选定的 `.xlsx` 在同一文件夹。
- 开始检测前检查报告目录写入权限。相同保存路径已经存在备份时会提示确认覆盖（建议每轮选新文件名）。写备份失败时程序会中止扫描并请求停车，而不是静默继续工作。
- Excel 使用临时文件写入和原子替换。若目标 Excel 正被 Excel 软件占用，原文件不损坏，备份仍保留；关闭占用程序后可恢复。
- Excel 生成三个工作表：**检测汇总**（统计/误差曲线）、**逐点结果**（25列测量明细）、**校准与参数**（校准与测试条件）。
- **对 V1.2 已经完成、但没有写出 Excel 的历史采点：** V1.2 没有逐点备份机制，若程序已退出，不能从仅有的截图或空报表恢复 74 点数据。V1.3 备份只保护升级之后的新扫描。
- V1.3 离线测试覆盖实际 Excel 写入+再读取、中文报表、74 点统计及备份恢复。DLL/串口的真实硬件行为仍需现场验证。
