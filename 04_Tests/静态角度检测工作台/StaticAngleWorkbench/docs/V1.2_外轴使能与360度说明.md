# V1.2 外轴使能诊断 / 0~360°

你提供的反馈为：内轴[enabled=1, normal=1, fault/limits=0]；外轴[enabled=0, normal=1, fault/limits=0]。
这代表外轴2没有使能，不代表外轴通信口错误或已经出现硬件故障。IMU COM3、转台 COM2 已能够打开。

## 联调流程

1. 确认实体急停正常，现场无人员靠近运动区域，先不要自动扫描。
2. 连接转台后点击「诊断状态」；若仅外轴2未使能，点击「使能外轴 2」并确认。
3. 日志应包含：`SetAxisEnable(2)`调用、DLL返回、回读 `GetAxisEnable(2)` 与 `GetAxisNormal(2)` 的最终反馈。
4. 若 enabled=1 且 normal=1，说明使能确认成功；再做安全条件下的低速、小幅手动定位，确认转向/制动/路径。
5. 若 DLL 调用失败或回读仍为0，**不要直接尝试自动检测，也不要绕过使能判断**。检查实际驱动供电、电控急停/联锁、驱动器报警指示和设备面板；尝试用原上位机手动使能外轴2作对照（不能让两个程序同时占用端口）。

## 角度范围

内轴 Axis0、外轴 Axis2 控制面均允许 0～360° 位置；自动测试计划原角 -180～180° 会映射为 180～360°～0～180° 的目标值序列，逻辑上保持等效角度。
不应在未经现场确认路径与线束安全前直接进行全圈扫描，也不应把位置到 0° 与实际机械找零等同。
