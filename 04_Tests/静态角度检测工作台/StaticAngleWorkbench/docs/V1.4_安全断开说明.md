# V1.4 安全断开与异常保护

## 风险说明
不能保证软件在断电、进程被强制结束、操作系统崩溃、厂商 DLL 原生崩溃、USB 断线等全部情况下“永不退出”或确保设备停车。软件急停不能代替独立于 PC 的实体急停与限位保护。运行前必须验证硬件级联锁和急停功能。

## 安全断开流程
1. 断开命令优先级高于待执行的运动命令，清空尚未发送的运动队列。
2. 分别处理内轴0与外轴2停车；未使能且反馈已经零速的轴不强发停车命令；不把 DLL 返回0误认成已停车。
3. 读取双方新反馈，连续至少三次确认角速度不大于 0.05°/s、位置稳定。
4. 分别解除使能并等待双方反馈 enabled=0（需连续两次）。
5. 只有上述检查全部通过才 ClosePort；失败时保持连接、报警且禁止新扫描。
6. 自动扫描期间点击安全断开，先发起中止、自动导出已有结果，再进入上述断开流程。

## 报告
完成、用户终止、质量异常终止时自动写 Excel；开始前设置路径。每采点持久备份 checkpoint；最终 Excel 写入失败仍可用“恢复备份”。已取消“导出已有结果”按钮。

## 异常与反馈
Python 未捕获异常写 `%LOCALAPPDATA%\\StaticAngleLab\\logs\\workbench_errors.log`。反馈丢失超过阈值时锁定自动检测。控制线程异常时提示机械安全状态未知。

## 验证边界
离线模拟驱动测试不能替代 2TD600 实机试验；DLL 停车返回值、使能响应、串口断线、移动路径、回零功能需要现场按硬件说明书核对。
