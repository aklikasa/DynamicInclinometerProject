# V1.1 修复说明

- COM：真正扫描操作系统 `serial.tools.list_ports.comports()`，两个不可编辑下拉框只保留真实COM设备及设备描述；不存在就让用户检查驱动。旧版 COM4/COM5 为硬编码默认值，已移除。
- 使能：旧项目打开端口后调用 `SetAxisEnable(0)`、等待0.1s、`SetAxisEnable(2)`、等待0.5s。旧版新程序却在使能前要求 `GetAxisNormal(轴)` 已为1，有可能在未上电的硬件上造成不能使能的死锁；修正为用户确认后发送使能指令，等待至少0.5s，读取 `GetAxisEnable` 和 `GetAxisNormal` 回执。故障、限位、超速、超差仍阻断使能。
- 新增一键「使能双轴」、逐轴使能、轴状态诊断、详细错误提示。不会自动上电，也不会自动运动。
- IMU：警告原来的控制变量 `error_streak` 在每次成功采集之后被重置为0，因此成功采样时每帧都打印。改为本次连接最多提醒一次；状态恢复也最多提醒一次。
- DLL 和数学扫描模块保持与V1的兼容；尚未验证现场转台上电、实际运动方向和运动跨零路径。
