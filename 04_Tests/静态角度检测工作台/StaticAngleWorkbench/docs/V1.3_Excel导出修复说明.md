# V1.3 Excel 导出问题修复

**原因**：V1.2 的 `app/core/report.py` 导入了 `artifact_tool`，这是在目标 Windows Python 环境中不保证存在的库，且原安装依赖与实际模块存在不匹配，导致扫描完成时报告保存失败。

**修复**：统一使用 `openpyxl>=3.1,<4`，完整生成三页 Excel；产出前使用同目录临时文件，保存完成再原子替换正式目标。

**数据保护**：扫描前检查报告目录写入许可，逐点原子落盘 `*.checkpoint.json`；意外中断、Excel 被占用或导出错误时，可点击界面「恢复备份」不连接设备重新生成 XLSX。

**提示**：恢复机制无法追溯 V1.2 已关机且没有备份的历史测量；原有实机安全与外轴使能控制逻辑保持不变。
