# TILT LAB V3 · Liquid Glass 浅色交互原型

## 立即体验

双击 `TILT_LAB_V3_Apple_Liquid_Glass_浅色交互原型.html`，即可在 Chrome、Edge、Safari 等现代浏览器中打开。它是**单文件离线演示版**，无需部署、无需网络或数据库，也无需安装依赖。

## 源码结构

- `index.html`：主页面，引用项目内 CSS 与 JS。
- `styles.css`：V2 的结构布局与功能模块基础样式。
- `liquid-glass.css`：V3 浅色 Liquid Glass 视觉覆盖层，可以独立修改并持续迭代。
- `app.js`：页面交互、模拟数据、图表渲染与弹窗逻辑。
- `V3_preview_overview.png`：全局总览界面。
- `V3_preview_monitor.png`：动态监测界面。
- `V3_preview_mobile.png`：移动端布局示意。

## 本版重点变化

1. 将暗色工业后台转换为珍珠白、冰蓝与淡紫色的浅色视觉。
2. 将玻璃质感主要放在浮动导航、工具栏、按钮和弹窗，曲线/表格/设备指标保留高可读的数据内容层。
3. 统一圆角、半透明层次、柔和阴影、动效节奏，并响应系统“减少动态效果/降低透明度”偏好。
4. 保留 V2 的 9 个功能模块及大部分已有交互，修复浅色视图的曲线坐标与独立验证温点可读性。
5. 补齐窄屏顶部导航和移动端侧栏折叠的视觉适配。

## 已测试

在 Chromium 中验证：九个页面切换、设备搜索与离线过滤、监测信号切换、画面暂停、告警确认、新建模拟实验、移动端菜单展开，均能运行，未发现 JavaScript 页面错误。

这是参照 Apple Liquid Glass 的**网页端视觉设计表达**，不是 Apple 官方组件或原生系统材质。全部设备、实验、波形和告警均为**模拟数据**；不连接真实硬件、温箱、转台、数据库和云服务，也不会发送任何设备控制指令。

如进入真实研发阶段，建议将数据接入、实验资源安全互锁、权限审批、数据存储、自动诊断与参数签名审计分别设计并验收。
