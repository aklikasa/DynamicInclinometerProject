# 2TD600 相对角度 ±360° 误限制修复说明

## 修复的问题
之前网页版手动“正转 / 反转”把相对角度误转换为“当前位置 + 相对角度”的绝对目标，并人为限制在 -360°～+360°。例如转台当前位置 350°、点击 +20°，会把 370° 错误拒绝。这不是设备说明书规定的相对位置上限。

2TD-600 原说明书 **附录 A.5** 明确区分绝对位置 D1 和增量位置 D6；厂家 `2TD600.dll` 确有 `SetAxisOpposition` 导出，原 R7 Python `twoTD600_SetAxisOpposition()` 已封装该调用。

## 本次代码改动
- 手动“正转 / 反转”直接给厂商增量位置函数发送 **带符号的角度**，不再合成绝对坐标，不设置 ±360° 的人为限幅。
- 例如 +20° 就发送 +20°，+720° 就发送 +720°，−540° 就发送 −540°；不能把它们分别缩成 +20°、0°、−180°。
- 到位反馈按**独立轮询的实际累计转角**核对多圈，不再只对角度取模；如果反馈间隔过长，无法确定累计圈数，会标记故障并尝试双轴软件停车。
- 为符合说明书的负载/轴间条件，内轴相对运动前须检查外轴为零位且静止，仍保留使能、找零、故障、限位、运动速度、反馈超时、软件停车等保护。
- 双轴“回到 0°”仍属于**绝对位置**，不等于机械找零，也不能拿它替代相对增量运动。

## 说明书与安全约束
- 厂家标称速度范围：两轴 0.01～60°/s；本 Web 仍沿用原 R7 的 10°/s 软件保护，**此次只修正角度逻辑**。
- 说明书关于连续转动的工装安装姿态、线缆空间、互锁、运动先后顺序和急停要求仍须遵守；无限制输入角度不代表无限制机械行程或线缆寿命。
- 0° 和 360° **朝向相同**，但对于 D6 相对运动 360° 是真实一圈，不能当作 0° 不运动。

## 更新（推荐小补丁）
1. **停止转台并保存数据**，关闭 R7 Web 后端窗口。
2. 把补丁压缩包里的所有文件解压到当前工程根目录，和 `Start_R7_Web_Win11.cmd` 同级。
3. 双击 `Apply_R7_TD_Relative_Angle_Fix.cmd`，出现 `[SUCCESS]`。
4. 重新运行 `Start_R7_Web_Win11.cmd`，浏览器按 `Ctrl + F5`。
5. 先做现场人员监护下的小角度/低速验证：对照原控制台确认正反转方向、真实角度和停车，再逐步验证跨越 360° 的行为。**不要第一步就执行多圈动作**。

补丁不会改写你的 `native_web_data/settings.json` 或现有 PCB/PLC 串口配置；自动温补、常温自动工艺的既有功能保持原样。
