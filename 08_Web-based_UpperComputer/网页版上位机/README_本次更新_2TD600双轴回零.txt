WK IMU R7 网页版：2TD600 手动角度解除试运行限制 + 双轴位置回零

改动：
1）内外轴自由输入小数相对角度，不再额外限制在 0.5–5° 单步。
2）去除额外 2°/s 试运行限速，采用原 R7 软件 motion_speed_guard.py 的 10°/s 上限。
    厂家手册额定速度 0.01–60°/s，但原 R7 软件上限是 10°/s；本次不解除原 R7 保护。
3）仍限制绝对目标角度在当前软件工作区间 ±360°；机械到位、故障、限位、超速、反馈超时等检查不取消。
4）新增“ 双轴回到 0° ”：先外轴至绝对位置 0°，确认反馈角度误差≤0.2°、速度低于0.05°/s、到位标志稳定≥0.5秒，再内轴归 0°。
5）这是“位置回到 0°”，不是执行厂家 SetAxisFindZero 的“机械找零”，要求两个轴已经完成机械找零。
6）双轴软件停车可以中止后续顺序动作；软件停车不能替代现场独立硬件急停。
7）自动常温 ACC/GYRO 标定尚未完成网页状态机迁移，不应由该手动按钮代替。

安装：
- 优先使用本次小补丁，避免覆盖你电脑上已配好的 COM 和 Python 虚拟环境。
- 在你现有的 R7 网页工程最外层（Start_R7_Web_Win11.cmd 同级）解压补丁内容。
- 确保转台停止、已保存实验后关闭原网页后台。
- 双击 Apply_R7_TD_Zero.cmd 完成备份与覆盖，再启动 Start_R7_Web_Win11.cmd。
- 浏览器按 Ctrl+F5 强制刷新页面缓存。
- 必须现场监督：先用低速短距离验证内外轴方向和软件停车；归零操作前检查线缆、工装和机械安全，硬件急停可用。

离线验证：52 项测试通过，其中 7 项专门覆盖顺序回零、到位静置、停止中断、异常保护。
