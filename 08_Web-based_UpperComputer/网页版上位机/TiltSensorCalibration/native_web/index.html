2TD-600 说明书标称内/外轴均为 0.01～60°/s

60°/s 是设备指标，不是已验证的网页标定限速。网页版已取消额外设置的 5° 单步、2°/s 试运行限制；仍沿用原 R7 的 10°/s 软件限速；相对角度直接使用厂家增量位置指令 D6，不再强加 ±360° 范围，并以实际累计转角验证多圈运动。连续旋转须符合轴间互锁、工装与线缆安全要求。
