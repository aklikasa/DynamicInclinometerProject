动态倾角仪工作台 · 保留完整转台运动控制 + 2FDT600WK 自动识别内外轴（基于本次上传的 DTS PCB 编号版）

1. 软件主界面的“轴状态”和“运动控制”页签均保留：角位置、速率、摇摆、停车、回零、两轴控制和状态反馈按钮没有被日志替代。
2. 2FDT600WK：点击“打开转台”时用被动方式逐个读取电脑串口，连续至少 2 帧有效厂家报文且分辨为 $1(内轴)、$2(外轴)时才连接；不需要选择 COM；找到后存入 config.xml 供下次优先检测。
3. 2FDT600WK：连接与使能分开。连接成功后再按左上方“使能两轴”，确认静止、急停释放、机械锁松开和人员安全，确认两轴进入 1# 伺服状态后才解锁原版控制按钮。打开连接时不自动回零。
4. 2TD600：界面也不要求每次选择 COM；先尝试已记忆的 COM，若不存在且仅剩一个合理候选可自动选择；但当前材料未包含可可靠被动识别 2TD600 的状态报文，不能保证系统有多个串口时自动区分 2TD600。无法唯一识别时安全地提示核对 config.xml 的 Turntable2TD600CommPort，而不是盲发可能引起运动的命令。
5. 全部厂商 DLL 和原来的 IMU 标定、DTS 设备编号、PCB 自动填入、温箱与运动控制代码保留。
6. Windows 下需要 pip install PySide6 pyserial numpy openpyxl 等原项目依赖，使用原项目 START_WORKSTATION.bat 或运行 main.py。

安全：先退出所有使用转台端口的软件，测控箱正常上电，轴系静止；带电不可插拔 RS422；请先小范围低速逐轴确认运动方向与停止/急停。
本修改仅离线检查；未连接实体转台进行现场验证。
