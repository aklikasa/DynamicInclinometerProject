# 温补不合格工况重试与常温统一｜2026-11-05

## 变更范围

基于「动态倾角仪上位机_28套温补模型_最终完整工程_20261105.zip」。仅修改温补自动采样发生 `robust_segment()` 质量拒绝后的**最大重试次数**，改为读取已经存在的常温生产工艺质量配置：

| 工况 | 旧温补版 | 新温补版（与常温一致） |
|---|---:|---:|
| ACC静态姿态 | 首次+2次重试 | **首次+5次重试** |
| GYRO静态零偏 | 首次+2次重试 | **首次+5次重试** |
| GYRO动态速率 | 首次+2次重试 | **首次+3次重试** |

- 源码：`form/form_thermal_compensation.py`，根据 `step['mode']` 读取 `t['profile']['quality']['static_sample_max_retries']` 或 `rate_sample_max_retries`。
- `production_quality_profile.json` 中对应默认值已经是 5 / 3，**未修改常温标定代码、工艺质量限值、原始数据单位、温补模型与报告算法**。
- 温补芯片温度极差0.5℃保持不变；无效数据仍不进入拟合、验证及Excel统计。
- 安全策略未放宽：机械故障和通信异常不走质量重试，动态重试仍必须停车并等待状态反馈。
- 质量不合格可以重试，但不能保证实测精度“绝对不受影响”；大量重试可能引起热状态变化，正式实验应检查采样期间累计温漂。
