# WK IMU 温补上位机 R7 — 直接目标SP / 完整12姿态联合温补

**版本定位：** 基于用户上传的 `WK_IMU温补上位机_R6_自动到首温_温控阈值可设置_不跳温_完整工程_20261110.zip` 修改的完整工程。保留旧有厂家DLL、Qt界面、PLC/WK通信、原始数据存储和回温/停车保护。未连接实际硬件进行验证；**不得视为量产放行程序**。

## 按本次需求修改的功能

### 1. 直接把目标温度写入PLC SP（不分级）

原R6首温/续做可分为5℃等多级SP。R7删除界面的“每级SP变化、阶段PV容差、每级超时”等参数，不再创建 `auto_arrival_stages`，不调用 `initial_stages()`；每个温度点直接通过原PLC接口写目标SP，仍等待SP回读和运行状态确认，WK在到温/热浸期间保持停车。设备制造商的实际升降温速率及保护不受上位机SP写入方式约束。

**注意：** 这是删除软件中间SP步骤，不是关闭PLC独立硬安全，也不能证明温箱允许大跨度目标SP变更。第一次低温/高温运行前必须有人值守确认温箱、PCB、夹具、线缆、电气和冷凝风险。

### 2. 取消“跨姿态温差0.6℃整组作废”

不再因ACC 12姿态间均值相差0.6℃、2℃或其他数值而删除已接受的12姿态、整组补采、或因该原因中止任务。跨姿态温差**不设新硬性阈值**；记录每组实际 `chip_min_c`、`chip_max_c`、`chip_span_c` 和工况数，结束时输出 `temperature_group_chip_temperature_audit.json`，Excel《温度质量审计》也显示实际跨度。

注意：**12个拟合姿态依旧必须全部完成**。若单工况失败或设备故障，沿用R6的补采、安全中止、恢复检查点与不跳温规则。单工况采样窗口芯片温差仍采用原R6 `temperature_span_max_c=0.5℃`；这是短采样窗口质量要求，与多姿态之间可发生2℃漂移不是一回事。若出现单工况超限，不会自动接受坏数据。

### 3. 芯片温度自变量：逐工况平均，不是温箱设定值，也不是整组均温

原始帧经过既有两级3σ去噪及单工况质检后，统计当前有效帧的芯片温度：
`T_i = mean(T_die of accepted frames in condition i)`。

在**生产自适应**质量模式下，每个拟合温度点ACC 12姿态仍然形成一个**完整的联合实验设计**，而不是12套单独标定；所有拟合温度点的完整姿态组共同建立

`raw_i = F(T_i) @ g_ref_i + b(T_i)`

其中 `F(T)` 是一个温度相关3×3矩阵，`b(T)` 是一个温度相关零偏向量。B/C/D、一到三次多项式和T0/T1/T2温度输入使用同一联合求解逻辑；A0仍是基准常数矩阵。内部以 `(T_effective−25)/50` 稳定数值求解，再转换为原上位机部署约定 `(T_effective−25)^k` 系数。T1/T2只在同一次实验有可靠PLC PV配对时评估；运行时仍只需芯片温度。

程序检查完整姿态组和设计矩阵的代数秩，若确实缺姿态或温度与姿态混淆使模型不可辨识，明确报告失败；不会为避免中止而虚构温补系数。原R6的候选选模与独立验证机制保留，**没有加入用户不需要的“提高≥5%”新增门槛**。

### 4. 与老版本的关系

**新实验：** 在IMU自动温补页面，生产扫描点“加载方案”后默认选择 `生产自适应`。同一任务记录 `temperature_quality_mode=production_adaptive`，离线28模型选型据此自动使用逐工况T联合拟合。

**老R6数据：** 既有R6任务应使用原版R6续做。R7改变了不可变的实验状态配置和设温流程，不能默认将中止时创建的R6检查点当作R7新策略直接恢复。保留其原始数据，用于单独研究/对照；不可冒险跨版本接续控制设备。

**严格模式：** 可以继续使用原版严格PV/芯片准入门槛，但R7将“跨姿态温差”改为信息记录，任何模式都不再因整组均温跨度而删除通过单工况QA的记录。硬安全保护未禁用。

## 使用方法

1. 解压整个ZIP，不要只复制 `main.py`。
2. 安装原工程依赖（Python / PySide6 / NumPy / Snap7等，参照原工程R6说明），确认厂家DLL和驱动在本机可用。
3. 运行 `TiltSensorCalibration/main.py` 或 `START_WORKSTATION.bat`。
4. 在“IMU自动温补”选择生产方向并点击“加载方案”。质量模式应显示 `生产自适应`，设温区域应显示 `PLC直接设定目标温度`。
5. 在现场**有人值守**验证PLC/SP回读、PV、WK停机和设备报警逻辑，先短流程再做完整温区；本包没有在真实WK/PLC/−40℃设备上做过联调。

## 结果和局限

- 仍保留原28套模型、ACC/GYRO报告及独立验证。
- 组温差不作硬拦截不表示实际芯片温度可以随意快速变化：芯片温度快变、设备振动、转台回差、姿态与温度强相关都可能损害参数辨识与跨温泛化。
- 对温漂与姿态明显共线的批次，建议增加同姿态重复/交错姿态验证，但本次不强行增加任何新的数值阈值。
- 输出研究系数**不等于转台机械误差已独立认证或六轴物理对齐已通过**；原PLC/WK硬件安全保护不得绕过。
- R7修改了生产采集到直接SP的路径；只进行了离线源码/数学/状态机回归，不可直接承诺无人值守−40℃全温安全。
