# R7 常温 IMU 自动标定：Web 无 Qt 执行引擎更新

**已开发的软件链路：** 原 R7 ACC 24 / GYRO 32 工况（支持分别运行，或一键顺序完成 ACC+GYRO）、2TD600 逐轴绝对定位、GYRO 速率控制、停稳与新鲜度检查、真实 PCB 同一串口采样、原工艺质量重试、独立编码器差分测速、A/B/C 模型比较及 Excel/CSV/JSON 结果。

## 安装（已有可用 R7 Web 的电脑）

1. 确认设备实际停稳，原 R7 桌面程序关闭，停止现有 Web 后端。
2. 备份原工程和 `TiltSensorCalibration/native_web_data/`，特别是已采集的实验记录。
3. 将补丁 ZIP 中**全部文件**解压到与 `Start_R7_Web_Win11.cmd` 同一文件夹。
4. 双击 `Apply_R7_Ambient_Auto.cmd`，查看语法检查结果；然后启动 Web，按 `Ctrl+F5` 刷新浏览器。
5. 网页在 2TD600 页面新增“常温 IMU · 自动标定任务”区域。
6. **首次自动运动按钮默认不可用。** 必须先按《现场启用与验收.md》逐项验收并完成现场记录。

## 测试与限制

- 已通过 76 项离线单元测试、HTTP 自动任务接口与默认拒绝启动检查；测试使用假设备，不会向你的实体设备发指令。
- 无法在此环境连接现场 PCB/2TD600，因此真实 24+32 工况的运动轨迹、实际停机、模型精度、报告和不确定度仍需在现场验收。
- 自动机械找零需要在厂商控制器完成；本版自动任务启动前要求两轴已经完成机械找零。
- 转台的最高硬件额定速度 60°/s，原 R7 自动工艺速率限 10°/s；不绕过这项保护。
- 软件停车、失能、断开串口、控制柜急停是不同操作；网页软件停止不是实体急停。
- PLC 设温与 2FDT600WK 温补自动执行仍未迁移，本包只推进 **2TD600 常温 IMU ACC/GYRO 标定**。
