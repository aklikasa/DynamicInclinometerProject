WK IMU R7 Web 双转台修复版（白色界面）

本修复基于先前 R7 UID + 六轴曲线完整工程，增加独立的 2TD600 常温标定转台页面。

转台一：2TD600.dll，单 COM（默认从 R7 config.xml 读取 COM4，但不视为真实检测结果），只读端口连接/双轴 DLL 状态反馈。
转台二：2FDT600WK.dll，内外双 COM，原有 WK 温补设备状态反馈。

操作步骤：
1. 备份旧工程和实验数据，并停止旧 Python Web 后端；关掉旧桌面上位机，以免抢 COM。
2. 完整版可放独立目录，运行 Install_Web_Win11.cmd、Start_R7_Web_Win11.cmd。
3. 若使用增量补丁，必须先将补丁所有文件覆盖到原有 R7 网页工程同名路径（仅源码；不会覆盖 native_web_data 的设备设置和记录）。
4. 在网页左边“2TD600 常温标定转台”查看，手动选择真实 COM（不是自动识别硬件型号）；确认转台静止、急停可用后再测试只读连接。
5. 2TD600 厂家 DLL 无经验证的只读身份码，DLL 开口和读取数据不能证明设备型号。必须现场核对读数与转台控制器。

重要：当前 2TD600 没有自动运动、使能、找零、速率运行、常温 ACC/GYRO 标定按钮；这些尚未从原 R7 的 Qt 状态机完成迁移与现场安全验收。严禁把该包视为可执行全自动常温标定的软件。

请不要用浏览器当紧急停车按钮；现场硬件急停和机械限位必须有效。
