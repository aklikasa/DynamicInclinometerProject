WK IMU R7 网页版 · 2TD600 按钮连接 + 手动控制试运行
====================================================
本版本基于您上传的原 R7 完整工程和上一版可采集真实 PCB 的 Web 工程。

这次实做：
1. 打开网页时，不再自动连接 2TD600，也不自动扫描、打开厂家 COM 口。
2. 在 2TD600 页点击【自动扫描串口并连接】，才由 Python 调用 Windows pyserial 枚举。
   - 如果仅有一个可用、未被 PCB/WK 预留的 COM：尝试建立 2TD600 通讯。
   - 如果同时有两个或以上候选 COM：拒绝乱试，页面列出 COM；请选择实际转台的 COM 后用【连接选中串口】。
   - DLL 不提供转台身份码。没有硬件身份可核验，因此不逐个尝试打开所有 COM，更不自动发送运动指令。
3. 删除页面上的“设备识别码/USB 序列号绑定/打开网页自动连接”等控件。
4. 新增 2TD600 内轴、外轴单步位置调节和双轴软件停车：
   - 原 R7 2TD600_SetAxisPosition / 2TD600_SetAxisStop 方法，非模拟硬件。
   - 单次只开放 0.5°、1°、2°、5°；正反方向；位置速度不超过 2°/s。
   - 发运动前：现场机械安全确认；双轴使能、已找零、故障、超速、限位、速度、实时反馈的检查。
   - 运动中继续监视反馈、到位、速度和故障；异常尝试软件停车。
   - 软件停车不是独立的硬件 E-STOP，失联/死机/断电时不能保证软件停车。
5. 保留已能使用的 PCB 实时采集、UID、曲线、PLC/WK 监测、R7 算法与记录。

重要边界（不能掩盖）：
- 2TD600 手动位置指令实际发送和现场停止保护尚未在您这台 Windows 11 实机转台验收。
- 原 R7 的完整 ACC 12+12 姿态、GYRO 正反转多速率、采样重试、自动找零、模型拟合报告的
  自动执行状态机仍和原 Qt UI 的定时器/采样队列耦合。当前尚未迁移为独立的 Web 自动控制，
  所以没有开放“开始完整常温标定”按钮。不会假装已经完成。
- 本版本不启用 PLC 写 SP 或 WK 转台运动。

安装：
建议先备份当前正常工作的 R7 Web 文件夹；关闭浏览器后台和原桌面 R7。
(1) 只用补丁时，将补丁与 Start_R7_Web_Win11.cmd 放到同一个目录；双击 Apply_R7_TD_ClickJog.cmd。
(2) 完整包按原版先运行 Install_Web_Win11.cmd，然后 Start_R7_Web_Win11.cmd。
(3) 浏览器 Ctrl + F5，进入“2TD600 常温标定转台”。
(4) 首次仅点击“自动扫描串口并连接”，核对真实角度变化；
    具备独立硬件急停、无人处于运动区域、机械限位/线缆检查完毕后，
    才在现场监督下尝试 0.5° / 0.5°/s 的单步运动。

不能只依赖网页版的“软件停车”保安全；现场人员应随时可操作转台物理急停。
遇到运动异常，立即使用转台硬件急停，停止网页操作，并发送后端启动窗口/日志截图。
