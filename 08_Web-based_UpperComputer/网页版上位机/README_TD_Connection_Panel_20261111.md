# R7 白色网页版：2TD600 断开通讯与实时状态面板

## 本次修改（实际已实现）

- **独立“断开转台通讯”按钮**：不再使用容易误解的“检查并断开”。
- **软件停车与断开分离**：转台停止并不代表断开串口；断开串口也不代表停止电机、失能或切断控制柜电源。
- **防误断**：有未完成的运动/归零序列、运动反馈未停、轴状态非静止或反馈异常时，后端拒绝直接断开，继续保持通信以便状态监测。点击断开需要再次确认。
- **删除右侧蓝色大段“一键自动扫描并连接”的重复提示**，替换为实时状态区：当前 COM、最近有效反馈延迟、使能状态、运动状态及后端反馈消息。仅使用已连接设备的数据；未连接时显示“—”。
- **保持按钮式扫描与连接**：网页打开不会扫描后主动占用未知转台 COM 口。若检测到多个候选串口，仍要求人工选择。

**不包括**：机械找零、控制柜电源远程断电、厂家伺服失能逻辑调整、ACC/GYRO 自动标定执行。这些没有在本次补丁中假装完成。

## 安装（Win11）

1. 在现场确认转台完全静止；保存 PCB 采集记录。
2. 关闭网页 Python 后端（运行中的 `Start_R7_Web_Win11.cmd` 窗口）。
3. 将补丁 ZIP 的**全部内容**解压到现有 R7 网页工程根目录，和 `Start_R7_Web_Win11.cmd` 放在一起。
4. 双击 `Apply_R7_TD_Connection_UI.cmd`。脚本会备份现有 4 个网页相关文件并覆盖更新。
5. 双击 `Start_R7_Web_Win11.cmd`，浏览器按 `Ctrl + F5` 强制刷新。

**若还需要连接原 R7 桌面程序进行标定，必须先关闭网页后端，避免同一 COM 口被两个进程占用。**

## 两种按钮的真实含义

| 操作 | 会发运动控制指令吗 | 会关闭 COM 吗 | 会关闭控制柜电源吗 |
| --- | --- | --- | --- |
| 双轴软件停车 | 是，发厂家的软件停车 | 否 | 否 |
| 断开转台通讯 | 否，仅在确认静止后释放 DLL 串口 | 是 | 否 |

控制柜**总停止/断电**须按设备厂家说明书现场执行。软件停车不是硬件急停。

## 验证范围

本更新已进行 Python 语法检查、JS 语法检查、只读 HTTP 状态接口启动测试、包括模拟 DLL 的软件断开防护测试在内的离线单元测试，**未在真实 2TD600 上执行断开或运动测试**。首次使用时先在安全的静止状态下验证“断开转台通讯”是否能让 COM 释放并再次连接。
