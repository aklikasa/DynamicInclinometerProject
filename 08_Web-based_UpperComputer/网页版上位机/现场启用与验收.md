# R7 网页版 2TD-600 常温 IMU 自动标定：现场启用与验收

> **本文件不是实机验收记录。** 项目已实现自动运动、采样、模型计算的后端流程和离线测试；实际 2TD-600、PCB、控制柜、工装、限位、急停与停机能力只有你现场能验证。第一次安装**默认禁用一键自动运动**。

## 一、实现范围

- **一键全套：** 选择“ACC + GYRO”，先完成 ACC 24 个工况与独立报告，再等待新的真实 PCB 帧并开始 GYRO 32 个工况，保留两个独立报告。
- **ACC：** 原 R7 `production_calibration.py` 的 12 个拟合姿态 + 12 个独立验证姿态，按顺序逐轴绝对定位、到位等待、静置、真实 PCB 采样、质控重试、A/B/C 模型及报告。
- **GYRO：** 原 R7 的 32 个静态零偏及内/外轴正反向匀速工况，自动位置准备、目标速率输出、稳定等待、独立角度差分测速验证、PCB 同步采样、停车、重试及 A/B/C 报告。
- 真实硬件通信由 **同一个 Python Web 后端**独占；不启动 PySide6，不抢占第二个 PCB COM。转台读数从原 `2TD600.dll` 读出，不生成假数据。
- 每次动作都检查反馈新鲜度、使能、机械已找零、机械锁紧标志、驱动异常、限位、超速及软件限速；自动位置动作采用**外轴先回 0°，再改变内轴，再设定外轴**的顺序。每轴有到位/停稳确认；失败不跳步，尝试双轴软件停车。
- 报告由原 R7 的模型比较与 `save_model_comparison()` 生成 Excel/CSV/JSON。**不写 PCB 系数**，不自动判定“生产放行”。
- 原版 R7 的 **自动机械寻找零点**没有在本版 Web 自动执行。运行前必须先在实体控制器完成机械找零，并用实际状态确认。网页“双轴回到0°”是位置归零，不等于机械找零。
- 原 **温箱 PLC 设温、2FDT600WK 温补全流程**不属于本次 2TD600 常温标定迁移，仍未开放执行。

## 二、为什么自动运行默认锁定

2TD600 是能够产生机械危险的设备。PDF 厂家说明书 3.2 节额定内、外框速度为 ±0.01～±60°/s；原 R7 生产工艺仍把自动运动的速率限制在 **10°/s**。额定最大速度不表示你的安装工装、线缆、负载在该速度下已验收。厂家说明书 §10 要求旋转区域 3 米外无人，并在运动异常时使用实体急停。

网页里“自动标定”按钮只有在**完成现场验收后**才可启用。不要通过改 JS/后端代码或伪造状态绕开验收。

## 三、现场验收清单（操作员及设备负责人共同确认）

- [ ] 控制柜供电、独立硬件急停可操作；急停**按设备说明书实际测试**后确认生效，异常停机后的复位流程已掌握
- [ ] 人员离转台旋转区域至少 3 米；负载、夹具、线缆、连接器固定，确认全姿态不干涉
- [ ] 内轴、外轴机械找零已完成；轴锁紧机构处于允许运动的状态，实际反馈正确
- [ ] 手动在低速、空载或被批准的试验负载条件下分别验证内轴、外轴位置正反方向，角度和角速度反馈与实际动作一致
- [ ] 验证“软件停车”实际停止两轴，重复测试运动中停车和异常状态；确认**软件停车不等于实体急停**
- [ ] 验证双轴顺序定位的实际运动空间：外轴回0、内轴定位、外轴定位，以及各类工况的可能回转路径
- [ ] 验证原 R7 设备型号、转台 DLL、固件、COM 口与控制器匹配，未被其他应用占用
- [ ] 以真实 PCB 完成 ACC 静态采样，满足帧数/时间/量程/ODR/温漂检查；UID 和设备编号核对正确
- [ ] 以真实 2TD-600 进行 GYRO 正转/反转低速测试，独立编码器角度差分测速与实际工况一致
- [ ] 核对 R7 `production_quality_profile.json`，尤其静置时间、速率、可动范围、质量判定和重试次数
- [ ] 执行部分工况的强制断帧/超时/人工中止测试，确认不会自动跳至下一步，实际停车能够完成
- [ ] 研发负责人批准当前工装/传感器/转台组合用于**有人监护的常温自动标定**，并记录日期和操作员

## 四、完成现场验收后如何启用

由有资质的现场操作员在上述项目**真实通过**后，新建文件：

`TiltSensorCalibration/native_web_data/2TD600_SITE_COMMISSIONED.json`

内容格式如下，`operator` 按实际记录，其他两个 PASSED 只有真实验收通过后才能填写：

```json
{
  "model": "2TD-600",
  "motion_validation": "PASSED_ON_PHYSICAL_RIG",
  "e_stop_test": "PASSED_ON_PHYSICAL_RIG",
  "operator": "填写真实现场操作/验收负责人"
}
```

保存后刷新网页。此 JSON 是**现场人工签核记录**，不是转台硬件身份认证，也不能代替设备本身的物理安全联锁。

1. 打开原来的 Win11 `Start_R7_Web_Win11.cmd`，连接真实 PCB 与 2TD600；原 R7 桌面版必须关闭。
2. 检查机械找零、内外轴使能、无报警、速度为零，勾选 2TD600 现场安全确认。
3. 在 **2TD600 常温标定** 页面填写 PCB 唯一编号，选择重力参考符号。
4. 在“常温 IMU · 自动标定任务”点击 **一键运行 ACC 24 姿态**或 **一键运行 GYRO 32 工况**，阅读强制确认并持续留在现场监护。
5. 后端会逐工况采样并检查实际设备状态；质量不合格按照 R7 工艺重试，超限中止。
6. 点击“停止自动标定并停车”时，后台请求双轴软件停车并确认真实速度归零；失去反馈/停机未确认时，**立即按现场实体急停**。
7. 完成后在逐工况页面下方下载 Excel/CSV/JSON，并与原桌面 R7 的标定结果进行对照。未完成实机重复性/不确定度验收前不用于生产放行。

## 五、重要边界

- 网页或 Python 进程崩溃、Windows 蓝屏、断电、串口线松脱时，软件**不能保证**发出停车指令；硬件急停和现场控制柜必须负责最终安全。
- 任务故障不会自动恢复机械运动。未完成的采样日志保存在 `native_web_data/ambient_guided_runs/`，重新开始新任务前应核对已保存的记录。
- 如果两个可用 COM 口无法明确区分，自动串口扫描不会擅自连其他设备；首次连接需要人工确认。
- 厂家额定 ±60°/s，R7 软件自动工艺最高 ±10°/s。不能为追求速度擅自放大工艺限速。
- 本交付提供完整代码路径和离线测例，**不代表我已经在你的 Windows 11 实机通过测试**。应以现场实际测量与设备安全审查为准。
