# WK IMU R7 → 白色网页端：功能迁移对照

此对照以用户提供的 R7 项目源码为基准。网页服务不导入 PySide6，也不运行桌面 `main.py`。网页中没有假传感器数据；断开、过期或尚未收到有效帧时只显示空值和诊断。

当前交付属于“R7 独立网页底座 + 真实采集与只读监控 + 实验计划与离线分析”，**不是 R7 全部桌面功能等价的网页替代品**。硬件实测仍需在用户的 Win11 PC、真实 PCB、PLC、2TD600 与 2FDT600WK 上完成。不要让原桌面和网页同时争抢设备端口。

## 2026-11-11 · 常温 IMU 自动任务引擎更新

- 完成 Qt-free 后端自动任务模块 `native_web/ambient_auto.py`，使用原 R7 2TD600 厂商 DLL 和原来的 ACC24/GYRO32 工艺数据；带逐轴运动、匀速正反转、到位/稳定时间/真实反馈、质量有限重试、自动分析与软件停车。
