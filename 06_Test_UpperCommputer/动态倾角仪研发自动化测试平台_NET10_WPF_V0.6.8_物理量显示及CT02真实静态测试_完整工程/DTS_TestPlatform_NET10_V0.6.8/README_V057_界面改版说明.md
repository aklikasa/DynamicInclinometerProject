# V0.5.7 改版说明

本次只改 WPF 工作台布局，不改真实设备通讯和数据文件格式。

**你反映的问题**：左侧测试卡片区只能排两列，但仍占大块空间；右侧转台操作空间不足，需要内部滚动才能找到停止和轴状态。

**这次解决方式**：

1. 主窗口仍默认最大化，左侧测试区随窗口宽度自动调整到适合两列卡片的宽度，右侧使用剩余空间。
2. 右侧使用三个平级设备页签：`2TD-600 双轴转台`、`2FDT600WK 温控转台`、`IMU / 采集 / 补偿`；转台内外轴并排，操作区无内部滚动条。
3. 物理安全确认区固定在右下方，不随设备页签滚动；运行 / 停止 / 归零都在转台页内直接可见。
4. IMU 的实时状态、补偿选项与开始/停止采集在 IMU 页签；顶部真实 UID 全局可见，不因切换设备页签而消失。
5. 底部日志默认折叠，腾出更多垂直空间，可随时展开。

**如何更新**：建议先备份当前工程，然后解压完整工程；或把补丁里两个文件按同样的相对路径覆盖 `src/Dts.Wpf/MainWindow.xaml` 和 `src/Dts.Wpf/MainWindow.xaml.cs`。如使用补丁，请不要覆盖自己的测试数据、配置和标定 JSON。若也需要新增界面回归检查，可同步覆盖 `scripts/check_sources.py`。

**请在 Windows 实机验证**：窗口最大化下是否能完整看到转台两轴位置和“停止”按钮；低分辨率/125%、150% 缩放下是否发生裁剪；UI 自身显示不代表设备通信或运动联调已通过。先只做读取反馈检查，切勿未经现场安全确认就运行转台。
