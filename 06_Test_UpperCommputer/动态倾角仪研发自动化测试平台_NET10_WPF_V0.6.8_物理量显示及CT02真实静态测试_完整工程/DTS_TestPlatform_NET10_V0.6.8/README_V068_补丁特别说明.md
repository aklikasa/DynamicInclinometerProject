# V0.6.8 补丁覆盖注意事项（基于 V0.6.7.1）

**推荐直接解压 V0.6.8 完整工程，不与旧工程混合。**

如果必须在原 V0.6.7.1 工程上覆盖补丁：

1. 先关闭 Visual Studio。
2. 将补丁 ZIP 内所有文件夹按原结构解压到 V0.6.7.1 工程根目录，覆盖同名文件。
3. **运行 `scripts/upgrade_v068_remove_old_ct02.cmd`**。它只删除旧占位文件 `src/Dts.Tests/S1/CT_02_Test.cs`，保留新的 `src/Dts.Tests/S1/CT02/CT_02_Test.cs`。
4. 再打开 `DTS.TestPlatform.sln`，执行“生成 -> 清理解决方案 -> 重新生成解决方案”。

如果忘记第 3 步，旧类和新类同名，可能报 CS0101（命名空间已有 CT_02_Test 定义）。

注意：此补丁不修改用户设备的原有标定 JSON、不修改 STM32 固件、不修改 CT-05 运动策略。
