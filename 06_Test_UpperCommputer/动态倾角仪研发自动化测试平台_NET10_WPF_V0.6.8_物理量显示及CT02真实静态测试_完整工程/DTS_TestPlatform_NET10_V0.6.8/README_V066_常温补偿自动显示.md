# 从 V0.6.5 升级至 V0.6.6

选择标定总目录，连接当前 UID 的 PCB 后勾选 **常温标定**。程序将每批收到的真实 int16 六轴数据按对应 ACC/Gyro JSON 的量程、零偏和 3×3 矩阵进行实时换算，不再要求启用试算复选框。

对于 DTS872028：JSON 写有 ACC ±2g 和 Gyro ±2000°/s。程序首先按这些参数把 int16 原始计数转换为 g、°/s，随后按矩阵计算校正后结果。结果行保留来源状态；MCU 未回报状态或量程不使六轴数值清空。

`imu_selected.csv` 保存与表格相同的换算结果，`imu_raw.csv` 始终备份原始计数。注意，数值能够计算并显示不等于已经通过计量验收：本版本只调整数据显示与存储，不会绕过转台故障/限位/使能验证，也未改变 CT-05 自动运动前置检查。

解压完整源码后在 Windows 使用 `scripts\build_windows.cmd` 编译；当前环境只做静态检查与用例代码审查，无法运行 Windows .NET 10 和硬件。
