# 从这里开始 · V0.5.8

1. 打开 `DTS.TestPlatform.sln`，确认 `Dts.Wpf` 是启动项目。
2. 在 Windows 运行 `scripts\build_windows.cmd`；遇到编译错误先提供首条真实错误，而不是“找不到 exe”。
3. 在 WPF 右侧设备工作台选择 `IMU / 采集 / 补偿`，表格自动显示新数据、滚动到最新。
4. 选择标定总目录一次即可，自动递归匹配 UID 文件；勾选常温/全温时使用该模式显示和主文件记录。
5. 点击“开始采集”，可选择限时自动停止或再次点击手动停止。
6. 检查 `imu_selected.csv`（选择模式主记录）、`imu_raw.csv`（原始备份）、`manifest.json`（身份/版本/有效性）。
7. **量程为 0 或未报告 SENSOR_OK 时，补偿值不可信，表格/主文件使用 -- 和状态码，不允许把这类数据作为正式试验验收。**

细节见 `docs/V058_采集显示与记录一致性.md`。
