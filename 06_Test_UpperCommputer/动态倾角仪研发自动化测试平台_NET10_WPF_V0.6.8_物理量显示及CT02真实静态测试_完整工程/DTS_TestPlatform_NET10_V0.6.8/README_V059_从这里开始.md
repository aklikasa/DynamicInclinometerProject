# V0.5.9 从这里开始

打开 `DTS.TestPlatform.sln`，设置 `Dts.Wpf` 为启动项目。也可以先运行 `scripts\build_windows.cmd`。

- **单独采集路径**：右侧页签“IMU / 采集 / 补偿” → “采集数据保存到”旁边“选择路径…”。该路径与顶部报告目录无关，自动记忆。
- **2TD 自动扫描**：右侧页签“2TD-600 双轴转台” → “自动扫描”，再确认端口并连接。
- **温控转台自动扫描**：右侧页签“2FDT600WK” → “自动扫描”，分别识别内外轴 COM，再确认并连接。

详细注意事项见 `docs/V059_采集目录与双转台自动扫描.md`。

**重要**：Windows/.NET 10 和真实硬件尚未在此执行环境测试。扫描不会自动运动，但不能代替现场的物理急停和控制器安全检查。
