# V0.6.3 界面布局与状态显示优化说明

基于 V0.6.2 的**纯界面调整**。保留原有 .NET 10 WPF 工程、84 项测试、真实 IMU/双转台驱动、UID 绑定、补偿、数据记录和原运动安全逻辑。

## 本轮修改

1. **测试卡片真正两列布局**：旧 `WrapPanel + 固定卡片宽度` 在部分 DPI 下把第二个按钮挤到下一行。现改用 `UniformGrid` 等宽两列；极窄的测试区（约少于 392 WPF 设备无关单位）自动回退一列，不会挤坏字。
2. **顶部目录缩短**：报告根目录、标定总目录保留各自选择按钮与可复制的路径，但只占顶部区域左边。右侧增加三个设备状态卡：IMU / PCB、2TD-600、2FDT 温控转台。
3. **状态卡由实际连接与反馈更新**：绿色表示已确认的连接/状态（2TD 需双轴使能等正常反馈）；橙色表示 2TD 仅诊断/未核验，温控转台不把未确认的使能状态显示为正常；灰色为未连接。2TD 过期反馈（>4秒）不显示“正常”。
4. **连接按钮简化**：设备页面内写“连接”或“安全断开”，不再用“连接并使能”作为按钮标签。注意：**2TD 连接后符合安全条件仍然会尝试自动使能**，这部分行为本版未修改，按钮提示也会说明。
5. **实时六轴表格升级**：主窗口与独立放大窗口共用样式；蓝灰表头、交替行、悬停和选中高亮、数值右对齐、状态文本完整提示。没有修改数据转换、采样频率或 CSV 内容。

## 替换说明

已有 V0.6.2：关闭程序和 Visual Studio，将 `V0.6.3_界面补丁.zip` 解压到 **解决方案根目录**并覆盖相应文件。

建议在 Windows 上运行：

```powershell
.\scripts\build_windows.cmd
```

随后在 Visual Studio 中将 `Dts.Wpf` 设为启动项目。推荐在 1920×1080 / 100%、1920×1080 / 150%、1366×768 / 125% 三种显示环境做实际视觉检查。

## 特别注意

- 本版没有调整两套转台的 DLL 接口、运动命令、速度限制、使能策略、安全互锁及断开流程。2TD 的“连接”按钮只是**改了文字**；安全确认仍必需。
- 软件上的绿色“2TD 双轴正常”要求真实反馈有效。温控转台使能语义仍待厂家协议核实，因此在线卡使用橙色提示，不伪造状态。
- `*.csv`、标定文件、原始 UID、测试报告的生成与保存逻辑均未修改。
- 当前开发环境没有 Windows/.NET 10 SDK 或实体设备，**仅做源码/XAML 静态检查**，无法声称实机已经编译和运行。若 Windows 上编译失败，运行 `scripts/build_windows.cmd` 并查看 `build_logs/last_build_debug.log` 的第一条错误。
