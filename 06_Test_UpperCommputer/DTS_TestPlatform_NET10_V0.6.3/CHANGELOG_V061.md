# V0.6.1 更新摘要

- 2TD-600 手动相对运动使用 DLL 增量指令 `SetAxisOpposition`（原 Python 驱动签名交叉核对），取消软件 90° / 360° 增量限制；角速度遵照手册 0.01～60°/s，内外轴默认 10°/s。
- 2TD 连接时必须安全确认，读取静止反馈后自动双轴使能并回读；原使能操作按钮换成状态说明。
- IMU / 2TD / 2FDT 连接按钮支持状态切换和主动断开；2TD 静止+断使能反馈合格方可关闭通讯，温控转台因状态定义不明确需现场确认停车。
- 若仍有转台连接，正常关闭程序将提示先安全断开，避免误以为关闭串口等于伺服停车。
- 温控转台仍维持原保守限速/限角，且不实现无法确认反馈的自动使能。详见 `README_V061_运动连接与安全关闭.md`。

验证边界：静态源码检查通过；未完成 Windows .NET 10 编译和实体设备实测。
