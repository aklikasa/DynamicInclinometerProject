# V0.5.6 — 统一补偿模式与递归 UID 标定库

- 主窗口：**原始 / 常温 / 全温** 三模式。常温与全温复选框互斥；未勾选即原始模式。
- IMU：真实原始 int16 永远单独写入 `imu_raw.csv`，所选标定补偿输出写入 `imu_selected.csv`；量程无效时不生成伪造的物理单位。
- 标定目录：一次选择总目录，递归匹配任意子文件夹中的 UID/DTS 文件；相同内容去重、不同内容的重复类型拒绝自动选择。
- 独立 CT-05 窗口：不再要求手动导入 JSON；使用主窗口冻结的模式与当前 UID 参数快照，支持 ACC/Gyro/全温分别存放在不同子目录。
- 每次采集附带源文件哈希与冻结副本（`calibration_snapshots/`）；测试报告保留源路径和哈希。
- 维持安全策略：`simulation_only` 禁止真实补偿、完整 UID 冲突必须拒绝、真实设备运动前单独核实。
- 新增回归检查：递归查找、同内容副本、同类不同版本冲突。
- 未经 Windows/.NET 10 编译器、真实设备联调验证；请在 Windows 执行构建与实测。
