# V0.5.2 界面与缩放适配说明

## 设计原则

1. **先保护身份和数据。** DTS、24字符原始UID、连接状态永远在身份栏；报告保存根目录独立成行。未取得有效真实UID时禁用复制语义（按钮会提示）。
2. **最大化而不是无边框独占。** `MainWindow.xaml` 使用 `WindowState="Maximized"`。允许用户最小化，保留 Windows 任务栏和应用切换；避免覆盖现场其他控制软件和物理安全操作流程。
3. **自适应布局，而非缩小字体。** WPF 的 DIP 随系统 DPI 比例调整；主工作区 Grid 的 `1.12* : 1*` 自动分配测试区/设备区；屏幕较窄时导航移至顶部并调整卡片列数。这比对整窗应用 Viewbox 等比缩小更安全、可读。
4. **操作与结果分区。** 扫描/连接在一行，实际设备状态单独展示；转台手动控制仍在设备区，自动测试设置仍由独立子窗口承载。
5. **一致的控件语言。** `App.xaml` 统一 Button、TextBox 和 TabItem 的圆角模板及悬停/焦点状态。新增测试窗口继承大多数样式，不需要每个 `.xaml` 重写。

## 主要文件

- `src/Dts.Wpf/MainWindow.xaml`：窗口大小、顶部 UID、IMU 端口面板及按钮位置。
- `src/Dts.Wpf/App.xaml`：控件的统一圆角外观与测试卡片样式。
- `src/Dts.Wpf/MainWindow.xaml.cs`：`OnMainSizeChanged`、`UpdateTileSizing`、`CopyUidClick`、`ToggleLogClick`。
- `scripts/check_sources.py`：对控件错误属性、事件名和布局回归的静态检查。

## Windows 实机视觉验收建议

在 Visual Studio 里把 `Dts.Wpf` 设为启动项目，执行 `scripts/build_windows.cmd`。

- 1920×1080 @ 100% 和 125%：标题/UID 完整可读；右侧扫描按钮不伸长，主界面无需水平滚动。
- 1366×768 @ 100%：测试卡片根据宽度排为两列；如有必要收起执行日志；右侧只在转台选项卡内部纵向滚动。
- Windows 设置 150% 或更高缩放：检查 UI 合理换行与正常键盘焦点，不强求单屏显示全部转台参数。
- 先连接真实 IMU、读取 MCU 原始 UID：确认展示完整 24 字符，与原设备编号一一对应，复制按钮可复制完整内容。
- 按阶段切换 S0/S1/S2/S3/S4，点击 CT-05 打开独立窗口、选择根目录、确认测试仍能进入原流程。
- 两套转台只读反馈先核验，尤其不得为了测试界面在未确认安全条件下驱动机械运动。

## 尚建议继续改善（未在 V0.5.2 实施）

- 全局显示密度（紧凑/标准），记录到本地用户设置。
- 设备状态加最后一次有效反馈时间，防止把过期读数误认为实时值。
- 长时间采集任务统一显式显示剩余磁盘空间、输出目录可写性和采样丢帧率。
- 两套转台建立可保存的设备配置档案，展示厂家状态码解释及软件限位有效期。
- CT-05 子窗口保留导入的扫描参数，避免反复输入，并加入结果预览图。

> 注意：本次是 UI 改版，没有改变硬件驱动/协议/安全策略；尚未经过 Windows 构建和设备现场联调，不声称已经通过整机测试。
