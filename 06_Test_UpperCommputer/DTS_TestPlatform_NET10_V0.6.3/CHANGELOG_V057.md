# V0.5.7 界面布局调整（保持 V0.5.6 实测通信和采集逻辑）

## 核心变化

- 左侧测试卡片始终以两列为主：在 980–1800+ DIP 宽度区间将测试区控制在约 430–565 DIP，不再为第三列留下大块空白，右侧设备区获得全部剩余宽度。
- 右侧改成 **2TD-600 / 2FDT600WK / IMU采集** 三个平级页签：每个设备独占工作台，不再堆叠 IMU + 转台造成控制面板高度被压缩。
- 2TD/2FDT 控制面板不包含内层 `ScrollViewer`；两个轴的当前角度、状态、相对角度、速度、使能、解除使能、运行、停止并排显示；所选轴归零、双轴软停车位于底部。
- 物理安全确认置于设备工作台下方，永久可见；启动时日志默认折叠，可按“展开日志”查看。
- IMU 串口、UID、补偿模式、定时/手动采集移到第三设备页签，原始 UID 仍保留在最顶部身份条。
- 不更改厂家 DLL 调用、运动方向/目标计算、UID 识别、标定文件自动匹配或 CSV/报告逻辑。

## 运行与验证

- 支持的编译目标仍为 .NET 10 Windows / WPF，启动项目 `Dts.Wpf`。
- 运行 `scripts\build_windows.cmd`，日志在 `build_logs`。
- 本次在 Linux 环境执行的检查为 XAML 结构、事件和控件名称对比，以及 84 项模块静态检查；无法在此完成 Windows WPF 实际编译或真实转台联调。
- 在低分辨率屏幕/高缩放比例下，控件视觉尺寸仍需现场确认；如发生挤压，请提供系统缩放比例和屏幕分辨率以做进一步响应式调整。**不能为消除滚动而让停止/急停不可见。**
