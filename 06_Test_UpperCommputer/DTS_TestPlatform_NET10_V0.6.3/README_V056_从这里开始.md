# 动态倾角仪研发测试平台 V0.5.6

## 快速上手

1. 将工程解压在**不包含旧 `bin`/`obj`** 的全新目录，例如 `D:\DTS_TestPlatform_V056`。
2. 安装 .NET 10 SDK 和含 WPF 的 Visual Studio 工作负载；执行 `scripts\build_windows.cmd`，确认 `Dts.TestPlatform.exe` 已真实生成。否则查看构建日志，不要直接 F5。
3. 打开 `DTS.TestPlatform.sln`，将 `Dts.Wpf` 设为启动项目。
4. 选择**报告保存总目录**和**标定文件总目录**，二者分开。标定文件可以在总目录的任意子文件夹里。
5. 连接真实 IMU 获取原始 UID；界面自动搜索其对应的四类 JSON。选择“原始 / 常温 / 全温”模式。
6. 只用真实数据先核验原始采集、定时停止及手动停止。CT-05 实物转台测试须在硬件安全和坐标/量程核实后执行。

详细约定请看 `docs/标定总目录与子文件夹规则.md`。本版所有实际驱动来自现有厂家 DLL/固件协议代码，但**未在本环境进行 Windows 编译或实机联调**。
