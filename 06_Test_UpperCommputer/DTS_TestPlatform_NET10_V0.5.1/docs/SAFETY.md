# 双轴转台现场安全与验收约束

1. **串口自动识别永不发送电机运动、轴使能、找零**。只读命令对非目标设备也可能有不兼容风险；接线前应先停止厂商应用并确认工作区域安全。
2. 两台转台的运动按钮必须由操作者勾选物理安全确认并在每次指令弹窗二次确认；手动停车按钮不要求二次确认。
3. 验证限位/零位/轴正方向/夹具/线缆转动半径/物理急停/地线后，才允许任何移动。
4. 软件 `StopAxis` **不是**硬件急停，不保证在 DLL 阻塞、断线、Windows 停机等工况下成功；需要独立的硬件电机切断/急停。
5. 严禁把 2TD 软件 ±180° 或 FDT ±30° 视为厂家机械限位。生产之前，应完成危险分析并把机械限位、两轴耦合碰撞包络写入设备专属配置。
6. 2TD 状态帧使用 0xA0 和手册的累加校验；若找不到端口，**不要用未知 COM 口盲发位置命令**，应检查串口接线、RS232/RS422、线速、厂家 DLL 版本。
7. FDT 串口扫描使用厂家 DLL 的 `GetStateInfo`，若单轴无法验证，不允许连接/控制整台温控转台。
8. 连接后的查询并非仪器计量校准；准确度检定与时钟对齐必须独立完成。
9. 现场首次实测依次为：断开负载且驱动未使能的通信验证 → 固定安全负载的只读反馈 → 专业人员监督下最小角度低速运动 → 重复性和长时测试。
